# Novel OS — External Advisory Integration Patch V1

**Status:** RELEASE CANDIDATE / ADVISORY LAYER  
**Does not replace:** Novel OS, Author Room Universe Hydration Standard, Character/POV evidence system, World Engine, Universe OS, continuity gates or editorial board.

## Purpose

Insert research-grounded external craft review where it can improve long-form storytelling without allowing an advisory layer to become a parallel authority or routine bottleneck.

## Governing placement

Current Novel transaction remains authoritative, with an optional consultation branch:

```
SOURCE INGESTION
→ VERIFICATION
→ SIGNIFICANCE
→ HISTORICAL CONTEXT
→ CHARACTER CONSEQUENCE
→ WORLD TRANSLATION
→ AUTHOR ROOM HYDRATION
→ CONSULT TRIGGER CLASSIFICATION
   ├─ NO_CONSULT → STORY ARCHITECTURE
   └─ TARGETED_PANEL / FULL_COUNCIL
      → EVIDENCE FREEZE
      → EXTERNAL SOURCE PACKET
      → INDEPENDENT ADVISOR READS
      → BULLPEN CROSS-EXAMINATION
      → RECONCILIATION
      → STORY ARCHITECTURE
→ SCENE / BEAT
→ MANUSCRIPT
→ OPTIONAL POST-DRAFT TARGETED CONSULT
→ EDITORIAL
→ CONTINUITY
→ CANON PROPOSAL
→ APPROVAL
→ STATE
```

## Critical ordering rule

**Author Room hydration always precedes advisory review.**

Consultants are not allowed to fill missing canonical facts, POV knowledge, geography or league evidence from imagination. If hydration exposes a load-bearing unknown, the engagement records the unknown and routes it back to the proper internal owner.

## Pre-draft consultation

Use when the unresolved issue is architectural:
- narrator / POV selection;
- chapter causality;
- ensemble balance;
- world depth;
- live-season serial structure;
- system legibility;
- exposition strategy.

Output: recommendations to Story Architecture, not prose.

## Post-draft consultation

Use selectively when actual pages reveal a problem that outline review could not expose:
- pacing;
- narrative distance;
- exposition leakage;
- repetitive entrances;
- structural redundancy;
- chapter ending / transition;
- outsider comprehension.

Output: editorial recommendations. The Beat Writer authors revisions.

## POV safeguard

The external council consumes, but does not originate, POV truth.

Required chain remains:

`Evidence → Temporal Character State → Relationship State → Knowledge Envelope → Narrative Significance → POV Eligibility → Scene`

Any consultant suggestion that requires unsupported private psychology is HOLD / NEED EVIDENCE or must be translated into observable behavior rather than certified interior fact.

## Live-season safeguard

Consultants review only evidence available at the engagement cutoff. They may propose branchable pressure but may not use later fantasy results to make earlier chapters appear inevitable.

## Consultant-to-canon firewall

No consultant memo enters canon directly.

`consultant recommendation → Bullpen reconciliation → internal artifact change → existing QA → canon proposal → approval`

## Invocation semantics

- "Bullpen, call the Novel consultants on this" = `consult`, advisory only.
- "Bullpen, have the Novel consultants fix this" = `mission`; consultation is an internal phase and Bullpen proceeds through implementation/proof unless a Jake-only gate remains.
- "Bullpen, get a second opinion before we write" = targeted panel selected from `ADVISOR_REGISTRY_V1.json`.

## Historical migration

The existing Prologue Tolkien-lens consult remains a valid historical precedent. It should be indexed as the seed case, not rewritten or falsely expanded into a council engagement.
