# NOVEL OS OPERATOR COMMANDS V1
Natural-language commands are routed to the smallest competent Bullpen team.
- **Bullpen, continue the Prologue.** Load V4 context, lineage, open promises and production state; do not import Week 1+.
- **Bullpen, ingest Week N.** Use Schemin Data Gateway; verify freshness/results before significance or narrative work.
- **Bullpen, audit Chapter N.** Run deterministic continuity + semantic Guardians; report blockers before revision.
- **Bullpen, resolve this character.** Resolve owner → canonical inhabitant → current team alias → current state → references.
- **Bullpen, produce next composition.** Resolve manuscript beat → visual value → reference packet → brief → composition → visual/continuity QA.
- **Bullpen, check canon.** Return authority-ranked assertions, conflicts, unknowns and provenance.
- **Bullpen, prepare next chapter.** Build bounded context packs, promises and causal consequences; draft only after gates.
## State vocabulary
PENDING → RUNNING → PASSED | FAILED | BLOCKED.
Routine implementation proceeds without founder interruption. Permanent major canon redefinition or irreconcilable source conflict escalates.
