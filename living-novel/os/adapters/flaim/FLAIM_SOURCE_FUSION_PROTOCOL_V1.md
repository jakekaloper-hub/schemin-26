# FLAIM SOURCE FUSION PROTOCOL V1
Flaim complements, not replaces, Schemin Data Gateway, ESPN evidence, commissioner evidence, Weekly Memo evidence, screenshots, explicit Jake corrections, Master Character Canon and historical records.
## Conflict resolution
Latest explicit Jake correction → binding shared evidence → approved canon → approved manuscript/visual locks → proven historical record → interpretation → proposal.
Freshness never overrides higher authority by itself. Equal-authority disagreement becomes CONFLICTED.
## Event identity
Prefer provider transaction/matchup IDs plus league/season/week. Duplicate observations merge provenance; they do not create two story events.
## Unsupported detail
Missing directional trade details remain UNKNOWN. A trade lifecycle row proves lifecycle activity, not the assets exchanged unless those assets are supplied.
