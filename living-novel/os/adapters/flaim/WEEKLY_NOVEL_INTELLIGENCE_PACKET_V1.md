# WEEKLY NOVEL INTELLIGENCE PACKET V1
For every finalized scoring week, assemble:
1. **Evidence:** final matchups, scoring anatomy when supported, standings delta, lineup/bench consequence when supported, transactions, FAAB, trades, roster/keeper change.
2. **Historical context:** prior meetings, postseason/title echoes, unusual scoring and recurring patterns. UNKNOWN stays UNKNOWN.
3. **Character consequence:** BEFORE → VERIFIED EVENT → AFTER, separated into FACT / INTERPRETATION / PROPOSED CANON / ORACLE.
4. **World consequence:** candidate changes to possessions, resources, reputation, threats, alliances, institutions or strategic position. No automatic one-to-one gamification.
5. **Story Promise effects:** OPEN / DEVELOPING / PARTIALLY_PAID / PAID / ABANDONED_WITH_JUSTIFICATION.
6. **Narrative candidates:** no prose / background / paragraph / scene / chapter movement / major arc.
7. **Visual candidates:** only after narrative consequence → visual-value gate → Master Character Canon/reference resolution.
8. **Rejected noise:** explicitly record weak/repetitive events excluded from prose.
9. **Provenance/unknowns/conflicts/temporal restrictions.**
