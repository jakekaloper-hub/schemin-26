# Novel Promise & Open-Loop Ledger V1

**Status:** RELEASE CANDIDATE — Author Council Engagement 001  
**Owner:** Librarian + Beat Writer

## Purpose

Prevent weekly closure from erasing long-form pressure.

## Loop states

- `PLANTED`
- `DEVELOPING`
- `PARTIALLY_PAID`
- `PAID`
- `DORMANT_WITH_REASON`
- `ABANDONED_WITH_JUSTIFICATION`

## Required fields

Each loop records:
- loop ID;
- origin artifact / chapter;
- story-time origin;
- participating entities;
- object/location if relevant;
- promise/question;
- reader knowledge;
- character knowledge by POV;
- current state;
- latest development;
- earliest legitimate payoff;
- prohibited premature payoff;
- candidate future pressures;
- closure evidence.

## Initial live-novel loop families

The following are categories, not invented outcomes:
- Belt possession vs current-form legitimacy;
- Jake / Austin competitive evidence;
- public reputation vs durable significance;
- provocation/receipt objects;
- undefeated-power attention;
- failed acquisitions and scarcity;
- damaged environments / repair obligations;
- altered character objects or appearance that require continuity;
- Archive selection bias / what gets preserved;
- world institutions reacting to the Twelve;
- prior-history threads that become relevant only when present conflict activates them.

## Rule

A source week does not close a loop merely because the scoreboard closes.

If a consequence still changes behavior, the loop remains open.

## Chapter dossier requirement

Every Chapter III+ dossier must state:
- loops entered;
- loops advanced;
- loops partially paid;
- loops paid;
- new loops planted;
- loops deliberately untouched.
