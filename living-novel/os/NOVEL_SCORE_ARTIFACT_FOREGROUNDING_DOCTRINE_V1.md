# Novel Score & Artifact Foregrounding Doctrine V1

**Status:** RELEASED / ACTIVE — Author Council Engagement 001

## Governing law

> **All verified numbers must remain true. Not all verified numbers must remain foreground prose.**

## Where complete numeric truth lives

- league/data evidence;
- verified ledgers;
- in-world scoreboards, receipts, standings and transaction artifacts where appropriate;
- QA provenance.

## A number belongs in narrative prose when it changes

- a decision;
- a relationship;
- a public interpretation;
- a wager/resource allocation;
- a rule application;
- a character's available options;
- a later causal chain.

## Foreground examples

Strong:
- a 1.50 margin when the entire scene turns on one decision;
- a record that changes supplier behavior;
- a bid amount that determines scarcity outcome;
- a score written on a returned provocation.

Weak:
- listing all six scores because six games occurred;
- repeated exact totals after the reader already understands blowout/close result;
- statistics that duplicate an artifact without changing action.

## Artifact rule

Use artifacts to carry comprehensive truth without forcing narrator exposition.

An artifact must still have story function. Do not insert tables merely because data exists.

## Anti-explanation rule

When object/action already communicates the point, delete or challenge the following explanatory sentence.

Common warning constructions:
- "This, too, was reputation."
- "Edrin understood..."
- "That was the consequence."
- "It meant..."

These phrases are not banned; they require proof that the scene has not already done the work.
