# Novel OS Core Engine v0.3
This directory contains dependency-light executable primitives, not simulated agents.
Current primitives: authority resolution, atomic JSON persistence, bounded context-pack assembly, command routing, character drift checks, Oracle-Time mutation guard, promise validation, acceptance gate.
## Contract
Deterministic checks execute before semantic Guardian review. A deterministic FATAL/IMPORTANT finding blocks acceptance. Generated content never mutates canon by calling these helpers alone; persistence of authoritative state requires an approval transaction.
