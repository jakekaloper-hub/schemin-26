# Living Novel OS v0.1

## Purpose
A repeatable, provenance-aware system for converting verified Pro Schemin' league history and live weekly events into a persistent secondary-world narrative.

## Layers
1. Evidence Layer — Flaim/ESPN + approved project canon.
2. Canon Registry — facts, confidence, source, temporal scope.
3. Interpretation Layer — significance and consequence mapping.
4. World Simulation — institutions, factions, geography, relationships.
5. Narrative Layer — scenes, POVs, arcs and manuscript.
6. Continuity Layer — contradiction checks and unresolved-thread tracking.
7. Publication Layer — approved canonical installments.

## Hard boundary
Sports data is never reader-facing merely because it exists. It is evidence used to determine magnitude, causality and consequences.

## Weekly transaction
verified_event -> significance_score -> fictional_interpretation -> consequence_graph -> continuity_check -> scene_candidate -> editorial_gate -> canon

## Branchable narrative pressure
Future results cannot be presumed. Establish desires, conflicts, debts, rivalries and institutions capable of producing coherent consequences under multiple future league outcomes.
