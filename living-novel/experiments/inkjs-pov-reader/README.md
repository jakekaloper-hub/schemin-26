# Schemin '26 inkjs POV reader — NONCANON EXPERIMENT
Issue: https://github.com/jakekaloper-hub/schemin-26/issues/148

This is **not** a new Novel OS and has no world/canon mutation authority. The twelve owner IDs mirror `canon/characters/CHARACTER_REGISTRY.yaml`; only ObiWan Jacoby and Three Dreaded Snake have temporary illustrative content. Neither narrative scene is approved manuscript prose.

## Running
Use Node >=22.19, install with `npm install`, run `npm test`, then `npm run dev` for the browser experience. The toolchain requires npm access to install inkjs 2.4.0 and Vite. Tests must be executed before claiming functionality.
