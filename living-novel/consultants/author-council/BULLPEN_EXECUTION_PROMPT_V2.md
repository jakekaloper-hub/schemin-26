# Bullpen Execution Prompt — Novel Author Consulting Program V2

`/bullpen mission — run the Novel Author Council from evidence freeze through audited implementation`

Proceed from the exact current `schemin-26` repository state.

## Objective

Use the active Novel External Advisory system to run author-method consulting with the same operational seriousness as FLA's Lunsford / Ezzell programs.

Do not return a roundtable of generic opinions.

## Required lifecycle

`/bullpen status`
→ `/bullpen research`
→ evidence freeze
→ consultant selection
→ independent Round 1
→ Bullpen cross-examination
→ `/bullpen reconcile`
→ implementation
→ test/editorial proof
→ Round 2
→ implementation
→ Round 3 adversarial review
→ corrective implementation
→ Round 4 final synthesis
→ `/bullpen audit`
→ `/bullpen learn`
→ `/bullpen next`

## Mandatory behaviors

- The Librarian freezes internal evidence before consultant review.
- The Scout verifies the public-method sources used for each named author lens.
- Each consultant reads independently before synthesis.
- The Beat Writer responds as narrative authority.
- The Analyst responds where a recommendation depends on evidence/significance.
- The Architect responds to Novel OS or workflow changes.
- The Umpire challenges completion and detects cosmetic compliance.
- The Closer reconciles conflict.
- Accepted recommendations are implemented between rounds.
- Advice is not considered learned until implementation survives audit.

## Output

Every engagement must create:
- evidence freeze;
- selected-consultant manifest;
- one memo per consultant per completed round;
- Bullpen cross-examination record;
- reconciliation;
- implementation decision;
- audit receipt;
- durable lessons, if any.

## Critical prohibition

Never write as if a named author personally participated.

Use:
**"J.K. Rowling published-method lens"**

Never:
**"J.K. Rowling told the Bullpen..."**

The same rule applies to all named author seats.
