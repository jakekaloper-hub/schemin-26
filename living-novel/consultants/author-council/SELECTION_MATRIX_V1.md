# Author Council Selection Matrix V1

**Rule:** select by problem, not by prestige.

| Problem | Primary | Counterweight | Usually avoid |
|---|---|---|---|
| World feels shallow / game-board-like | Tolkien | Le Guin | Grisham unless pacing also affected |
| Too much lore / chapter drags | Grisham | Tolkien | Full Seven |
| Wrong or leaky POV | Le Guin | Abercrombie + Martin | Sanderson |
| Ensemble feels like weekly recap | Martin | Rowling + Grisham | Tolkien alone |
| Long-term setups/payoffs weak | Rowling | Martin | Abercrombie alone |
| Rules / Contest mechanics confusing | Sanderson | Grisham | Rowling unless reveal-order issue |
| Epic action feels distant | Abercrombie | Le Guin | Tolkien alone |
| Chapter openings/endings weak | Grisham | Rowling + Abercrombie | Full Seven |
| Too many new world systems | Sanderson | Tolkien + Architect | Rowling |
| Mystery relies on unfair withholding | Rowling | Le Guin | Sanderson |
| Characters sound interchangeable | Abercrombie | Le Guin | Tolkien |
| Book architecture / week→chapter model | Martin | Rowling + Grisham + Serialized Continuity | Single consultant |
| Major canonical manuscript rewrite | Full Seven | Umpire red-team | none |
| New narrator constitution | Full Seven | Librarian / POV evidence | none |

## Named panel shortcuts

### World Depth Panel
Tolkien + Le Guin + Sanderson

### Story Architecture Panel
Martin + Rowling + Grisham + Serialized Continuity Editor

### POV / Character Panel
Le Guin + Abercrombie + Martin

### Pacing / Page-Turn Panel
Grisham + Rowling + Abercrombie

### Epic Fantasy Integrity Panel
Tolkien + Martin + Le Guin + Abercrombie

### Full Seven
Tolkien + Martin + Rowling + Grisham + Le Guin + Sanderson + Abercrombie

Full Seven is expensive in attention. Use only for cross-cutting architecture, not ordinary chapter edits.
