## Program architecture

The program mirrors the useful compounding behavior of the FLA Lunsford / Ezzell consulting pattern:

`pre-work → independent Round 1 → Bullpen cross-examination → implementation → Round 2 → implementation → Round 3 adversarial re-review → correction → Round 4 synthesis → audit → learn`

Each author seat is a PUBLISHED_METHOD_LENS with:
- a permanent dossier;
- registered public-method sources;
- standing questions;
- domain boundaries;
- Bullpen counterparts;
- four-round responsibilities;
- anti-imitation controls.

## Authority boundary

The seven authors are not represented as live participants.

They are research-grounded published-method consultants. Their public craft principles may challenge Schemin's work, but they cannot:
- promote canon;
- invent real-owner psychology;
- use future fantasy results outside the evidence cutoff;
- bypass Author Room hydration;
- override Novel OS / Universe OS / Character Canon;
- imitate a living author's prose;
- create fictional quotes or private opinions.

## Natural-language invocation

- `Bullpen, call Grisham on this chapter's pacing.`
- `Bullpen, have Rowling and Martin challenge the chapter architecture.`
- `Bullpen, run the POV panel on this scene.`

The Bullpen selects by problem, not celebrity.
