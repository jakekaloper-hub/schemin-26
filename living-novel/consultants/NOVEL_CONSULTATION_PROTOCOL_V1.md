# Novel Consultation Protocol V1

**Status:** RELEASED / ACTIVE  
**Applies to:** Living Novel external advisory engagements  
**Governing Bullpen standard:** External Advisory Program V1

## Stage 0 — Trigger

The Closer classifies the request as:
- NO_CONSULT;
- TARGETED_PANEL;
- FULL_COUNCIL.

The selection must be justified by the narrative problem, not prestige or name recognition.

## Stage 1 — Evidence freeze

Before advisors read the work, The Librarian records:
- Schemin commit / evidence cutoff;
- manuscript or architecture artifact in scope;
- current Novel OS and Author Room controls;
- relevant Character/POV packets;
- relevant world/location state;
- verified league evidence;
- known unresolved gaps;
- exact questions for review.

No advisor may silently use future evidence outside the cutoff.

## Stage 2 — External research packet

The Scout resolves the approved public source material for every PUBLISHED_METHOD_LENS.

Each source note records:
- URL/title;
- date accessed;
- method/principle being used;
- what the source **does not** establish.

Composite specialists receive a source-family list rather than a fabricated identity.

## Stage 3 — Independent reads

Each advisor gets:
1. identical frozen internal evidence, except explicitly documented specialist attachments;
2. its own source packet;
3. the same decision questions;
4. no access to the other advisors' conclusions.

Each independent memo must answer:
- What is working and should be preserved?
- What is the highest-leverage weakness?
- Why does it matter to a reader?
- What would you change?
- What would you explicitly not change?
- What project evidence constrains the recommendation?
- What are you least certain about?

## Stage 4 — Bullpen cross-examination

The Closer routes consultant questions and challenges to internal domain owners.

Minimum internal participants for major literary consultation:
- Beat Writer;
- Librarian;
- Umpire.

Add as required:
- Analyst for evidence/significance;
- Architect for system/OS changes;
- Scout for external-source claims;
- world/character/visual owners for their controlled surfaces.

Internal owners respond with evidence, not status.

Advisors then lock a final memo.

## Stage 5 — Reconciliation

The Closer produces a reconciliation record with four buckets:
- ACCEPT;
- ACCEPT WITH ADAPTATION;
- HOLD / NEED EVIDENCE;
- REJECT.

A rejected recommendation remains in the record with reason. Dissent is not erased.

## Stage 6 — Implementation decision

Only the internal Bullpen converts advice into work.

Potential outputs:
- story-architecture patch;
- chapter-dossier revision;
- POV-routing change;
- manuscript revision brief;
- worldbuilding research task;
- Novel OS proposal;
- editorial test;
- no change.

Any change affecting canon follows existing canon proposal/approval rules.

## Stage 7 — Post-change proof

For material changes, Umpire independently tests:
- factual/provenance integrity;
- temporal integrity;
- character/POV integrity;
- world continuity;
- literary objective;
- consultant recommendation traceability;
- absence of prose imitation / false attribution.

## Stage 8 — Learn

The Librarian records only reusable lessons that survived implementation and audit.

Consultant advice is not institutional learning merely because it sounded persuasive.

## Engagement IDs

Use:
`NOVEL-CONSULT-YYYY-MM-DD-NNN`

Each engagement folder should contain:
- `00_EVIDENCE_FREEZE.md`
- `01_SOURCE_PACKET.md`
- one independent memo per advisor;
- `RECONCILIATION.md`
- `IMPLEMENTATION_DECISION.md`
- `AUDIT_RECEIPT.md` when implementation occurs.

## Existing Prologue consult migration

The Tolkien-lens Prologue consult remains valid historical precedent. It is not retroactively rewritten as a multi-advisor engagement. New engagements use this protocol.
