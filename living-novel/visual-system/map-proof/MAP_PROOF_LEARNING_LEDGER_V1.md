# SCHEMIN’ ’26 — MAP PROOF LEARNING LEDGER V1

**Status:** LEARNED / FEEDS NEXT VISUAL PHASE

## L1 — Recto beats spread for the current master map
The Central Basin is both geographically central and narratively important. A physical gutter competes with it. Use the 6×9 recto as the default book map; keep the spread as an optional endpaper/digital treatment.

## L2 — Map hierarchy must remove information, not just shrink it
The 6×9 version cannot be a scaled-down 12×9 map. It needs fewer roads/labels and stronger priority. Regional maps own the detail.

## L3 — World memory is strongest as a temporal overlay
Mire Hill works because the base roads/location remain fixed while the scar/yield annotation is visibly separate. This should become the standard for future Week-state maps.

## L4 — Hydrology needs a future promoted vector if exact watercourse art becomes important
The current physical canon gives causal watershed logic, not an exact river spline. The proof may show schematic water flow; future publication-grade river geometry should be deliberately authored/promoted rather than inferred by an art model.

## L5 — Divisions do not need territorial coloring on M0
Leaving division borders off materially improves the one-world reading. Division context can appear in regional keys, cultural motifs or optional overlays.

## L6 — Deterministic SVG is the right base layer
It keeps labels, LOC positions, route topology and state overlays auditable. Painterly/AI treatment should be a surface pass over locked geometry, never the source of geometry.

## L7 — Book maps need page-design packets
The same Atlas data produces different useful pages because M0, M1 and M6B have different reader jobs. “One map export everywhere” would fail the book.

## L8 — Next map-art work should be aesthetic, not architectural
Topology has passed. The next cartography improvement should test Chronicle-style terrain/material treatment over the locked vector system without changing any position or route.

## Next-gate recommendation

Proceed to **ENVIRONMENT + OBJECT PROOF** in the visual roadmap while preserving the accepted map base. In parallel, a cartographic art-treatment prototype may be run on M0 recto using locked geometry.

Do not start full-book page illustration yet.
