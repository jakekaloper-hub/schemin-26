# SCHEMIN ’26 CARTOGRAPHY SYSTEM PLAN V1

**Authority:** Atlas Control Plane V2 + World Engine V1.1 + Universe OS V1.2  
**Novel role:** reader-facing cartographic views only; no independent geography

## 1. Cartographic doctrine

The Schemin book uses **one map language with multiple governed layers**.

All maps must preserve:
- seven-zone macro geography;
- stable location IDs;
- route topology;
- hydrology/elevation causality;
- owner-domain placement;
- world-state overlays;
- nonexclusive division logic.

Map appearance may change by purpose. Topology may not.

## 4. Map style tiers

### Tier A — Canonical Reference Cartography
Clean line/engraving geometry, restrained wash, accurate location/route relationships.
Use for master/regional maps and QA reference.

### Tier B — Chronicle Cartography
Same geometry, more illustrative terrain, material texture, small settlement/landmark vignettes.
Use in book.

### Tier C — Memory Overlay
Same base map + dated consequence layer.
Use for world-history/state spreads.

No tier may relocate a governed location to improve composition.

## 5. Cartographic symbology

Use functional symbols rather than invented faction heraldry:
- owner/home anchor;
- League institution;
- recurring civic location;
- encounter site;
- historic event site;
- road/pass;
- water route;
- weather hazard;
- active world-state scar.

Character/team sigils are PROPOSED ONLY until explicitly canonized.

## 6. Deterministic typography

All names/labels are post-composited:
- no generated text;
- stable location names from Atlas;
- provisional location status respected;
- region labels consistent across maps;
- north/orientation indicator stable;
- legend hierarchy consistent.

## 8. Layer distinction

### Geography
Terrain, hydrology, coast, elevation. Permanent base.

### Civil / owner domain
Settlements, institutions, home anchors. Persistent but socially editable.

### Division
Subtle cultural/competitive affiliation overlay. Never physical border.

### Travel
Roads, passes, causeways, ports. Topology.

### Encounter
Resolved venue/site for a specific event.

### World memory
Dated scars/history and state deltas.

### Narrative emphasis
Graphic hierarchy only—line weight, inset, vignette—not a canon layer.

## 9. Map production rule

Every map request must declare:
- map ID;
- reader job;
- temporal snapshot;
- Atlas layers consumed;
- location IDs;
- routes;
- visible world-state overlays;
- hidden layers;
- deterministic labels;
- unresolved/provisional elements;
- QA checks.

## 10. Book placement

Front matter:
- Master World Map.

Body:
- Central League inset near Chapter I;
- Wetlands route map near swamp sequence;
- one or two event/memory maps in Chapters II–III;
- Six Roads Forward at current ending.

Back matter:
- seven-zone overview;
- extended route index;
- Week 1–3 world-memory map;
- additional region plates if page count allows.

## 11. “How many maps is too many?”

For the present 110-page manuscript:
- 5–7 maps in front/body is the target;
- 8 is a soft ceiling before maps begin competing with prose;
- appendix maps are outside that ceiling if clearly separated.

Future full-season editions may add maps when new geography or consequential world-memory earns them; do not preserve a fixed map count.

## 12. Cartographic acceptance gate

PASS only if:
- stable IDs resolve;
- no second geography appears;
- no false division border;
- routes connect according to current Atlas;
- hydrology/topography are plausible;
- provisional status is not silently promoted;
- temporal world state matches manuscript scene;
- no future event is implied;
- deterministic labels are exact.
