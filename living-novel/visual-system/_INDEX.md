## Governing principle

**One persistent reality. One spatial control plane. Many publication views. No forked geography.**

The illustrated book is a Novel OS publication surface consuming League Truth, Character Canon, Universe OS / World Engine, Atlas Control Plane, world memory and manuscript state. It does not own independent geography or character identity.

## Page-composition law

Every final page/spread is designed from its actual narrative content. There is no default page template and no fixed visual quota. The current Word pagination is provisional; page numbers lock only after typography, visual dimensions, page-turn logic and QA are reconciled.
