- accepted map proofs;
- accepted environment/object structural proofs;
- neutral placeholders;
- silhouette-safe non-character markers.

Previs may not:
- promote structural environment proofs to final art;
- bypass principal character reference gates;
- lock final pagination before visual placeholders are integrated.
