# SCHEMIN’ ’26 — ILLUSTRATED BOOK VISUAL MASTERPLAN V1

**Status:** PREPRODUCTION MASTERPLAN  
**Lead:** The Beat Writer / Literary + Visual Narrative Director  
**Authority inherited from:** Project Mission, Novel OS v1.0, Memo OS V5.5, Universe OS V1.2, Atlas Control Plane V2, current Character Canon.

## Executive decision
SCHEMIN’ ’26 should become a **literary illustrated epic**, not a text novel with decorative inserts and not a fantasy-football guide disguised as a novel.

The visual system has four jobs:
1. **orient** — make geography, routes and institutions legible;
2. **embody** — make the Twelve, their objects and their environments memorable;
3. **remember** — show how places retain scars, receipts, repairs and reputational consequences;
4. **pace** — use silence, image, map, artifact and prose density to control the reader’s experience page by page.

The model is closer to an illustrated epic-fantasy chronicle than a conventional sports annual. It may be more visually dense than traditional epic fantasy because Schemin can maintain consistent world packets, character packets and visual QA, but prose remains the governing narrative surface.

## North-Star laws
- Weekly Memo, Novel, Atlas and visual production depict one world.
- Atlas provides spatial truth; book maps are views, never a new geography store.
- Character identity resolves OWNER → ACTIVE CHARACTER → current team name.
- World memory may overlay geography; it may not redraw base geography.
- Exact sports data is deterministic/typeset, never entrusted to image-model text.
- Page design is content-responsive: **the story determines the page**.
- Final recognizable principal-character generation remains blocked until current reference/provider subject-binding gates close.
- Environment, object, diagram, map and non-principal work may proceed now.

## Visual language
Material vocabulary: leather, paper, vellum, iron, brass, timber, repaired stone, wax, thread, mud, black water, smoke, rain, weathered paint, hammered metal.

Image language: monumental environment, atmospheric depth, motivated light, readable silhouettes, naturalistic materiality, quiet negative space, restrained wonder, seriousness with humor emerging from circumstance.

Reject:
- generic “fantasy poster” layouts;
- repeated centered hero poses;
- faux parchment on every page;
- sports-dashboard UI inside narrative pages;
- invented borders;
- random heraldry;
- arbitrary magic glow;
- image-generated factual typography;
- twelve-character prompt soup;
- retired Wilson centaur anatomy;
- Belt on Jake;
- identity blending.

## Visual density
Target the *rhythm*, not a fixed illustration quota.

Recommended book-level cadence:
- major chapter opener: 1 high-value visual;
- every ~3–6 reading pages: some visual event may occur, but can be a tiny object, map fragment or quiet margin rather than a painting;
- 1–2 major cinematic spreads per long chapter maximum unless story earns more;
- maps appear when spatial understanding materially improves the scene;
- artifact pages appear when evidence/receipt/object itself is story;
- quiet prose-only sequences remain necessary.

A page may deliberately contain no art.

| Class | Function | Typical placement | Character gate |
|---|---|---|---|
| Frontispiece | thesis / invitation | front matter | avoid principal faces initially |

| Encounter map | terrain / event comprehension | after/around major encounter | none |
| World-memory map | consequences over place | chapter close/appendix | none |
| Chapter opener | tone + narrative question | chapter recto | depends |

| Character plate | recognition | selective body/appendix | HARD GATE |

## Memo → Novel translation
Memo visuals are evidence and visual research, not book-page templates.

Translate:
- strong recurring objects → artifact studies;
- established places → environment plates/map anchors;
- meaningful spatial consequences → Atlas/world-memory overlays;
- successful cinematic beats → recomposed illustrations tied to novel prose.

Do not translate:
- scoreboards as UI;
- weekly ranking dashboards;
- meme-heavy typography;
- fixed mobile page ratios;
- single-week joke art whose meaning did not survive.

## Page-level doctrine
Every final physical page receives a Page Design Packet after typography preflight. The packet declares:
- manuscript anchor;
- narrative job;
- text volume;
- visual contribution;
- composition family;
- recto/verso role;
- spread dependency;
- art:text ratio;
- map layer(s);
- character reference state;
- image tells / prose tells;
- previous/next-page rhythm;
- bleed/gutter/safe-zone constraints;
- accessibility and print checks.

The current 110-page Word layout is not canonical pagination.

## Board ruling
The visual system should be **more visual than classic map-and-plate fantasy editions**, but the additional density comes from controlled diversity—maps, objects, place studies, diagrams, marginalia, quiet art—not from turning every page into a poster.
