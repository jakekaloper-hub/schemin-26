# SCHEMIN’ ’26 — PILOT VISUAL PACKAGE V1

**Status:** RECOMMENDED FIRST PROOF / NO FINAL ART YET

## Pilot objective
Prove that Schemin can feel like a coherent illustrated epic before spending effort on principal-character rendering.

## Six-asset pilot
1. **M0 Master World Map** — front-matter orientation.
2. **Record House / Archive plate** — establishes book materiality and institutional depth.
3. **Hall of Keeping object plate** — Farrell Trophy + Belt context without requiring a principal portrait.
4. **Southern Wetlands route/terrain map** — demonstrates geography changing story.
5. **Mire Hill world-memory plate/map** — demonstrates persistent consequence.
6. **Six Roads Forward horizon map** — demonstrates live-novel continuity without predicting outcomes.

## Optional seventh only if character gate is cleared
Trade Jedi environmental portrait at mountain base.

If not cleared, use the mountain base without a recognizable Jake figure.

## Why this pilot
It exercises:
- front matter;
- chapter-support art;
- cartography;
- object storytelling;
- world memory;
- route logic;
- page-template diversity;
- current/future boundary;
- no dependency on risky twelve-character generation.

## Proposed sample sequence
Title page → M0 map → pure literary page → Archive spread → artifact page → prose page → route map → environmental plate → Horizon map.

This lets Reader Experience judge rhythm rather than isolated beauty.

## Pass criteria
- reader can orient without a wiki;
- maps look like one family;
- art feels native to the prose;
- page types vary intentionally;
- labels remain readable at 6×9;
- world memory is visually distinct from base geography;
- no current canon violation;
- no visual requires explanation of the production system.
