# CANON CONFIDENCE MODEL V1

**Status:** BINDING FOR UNIVERSE OS V1.2 MIGRATION

Allowed confidence states:
- **LOCKED** — explicit Commissioner/current canon authority.
- **APPROVED** — accepted production/world standard.
- **INFERRED** — plausible connective worldbuilding, not explicitly locked.
- **HISTORICAL** — valid historical evidence, not necessarily current.
- **SUPERSEDED** — once-valid/used treatment no longer current.
- **UNKNOWN** — insufficient authority.

## Required metadata
Where applicable:
- status
- source
- last_verified
- review_owner
- supersedes
- superseded_by
- notes

## Rules
1. INFERRED never silently upgrades to LOCKED.
2. Generated art begins as UNKNOWN / NON-CANONICAL unless admitted by governance.
3. Historical publication is evidence, not automatic current authority.
4. A superseded asset remains retrievable for history but cannot control current production.
5. Field-level confidence may differ inside one entity.

## Current examples
- Wilson = Arsenal Gorilla Warrior: LOCKED.
- Wilson centaur: SUPERSEDED + HISTORICAL.
- ObiWan coexists with other Jedi: LOCKED by Commissioner directive.
- Exact unverified nearby farm placement near Trade Jedi Mountain Base: INFERRED.
- Abstract Atlas coordinates: APPROVED for topology, not metric geography.
