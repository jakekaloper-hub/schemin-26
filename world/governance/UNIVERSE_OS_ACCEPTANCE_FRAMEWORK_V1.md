- CIVILIZATION — settlements/economies/institutions follow geography.
- MEMORY — permanent/recurring/historical/temporary/joke distinctions.

- CROSS-OS — Memo/Novel/Art resolve same world IDs.
- MUTATION — provenance-bearing state change with rollback.

- VISUAL PACKETS — scene context cannot invent upstream truth.
- RETROSPECTIVE — Weeks 1–3 replay without grandfathering defects.
- CHARACTER SAFETY — current principal locks remain intact.
