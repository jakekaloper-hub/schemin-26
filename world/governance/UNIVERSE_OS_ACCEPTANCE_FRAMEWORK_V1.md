# UNIVERSE OS ACCEPTANCE FRAMEWORK V1

A phase is not complete because files exist.

## Geography
Can the system explain why a location exists, how it is reached, what water/terrain affects it, what it connects to and what state persists?

## Civilization
Can it explain who lives there, what communities/institutions/economies operate and how daily life is supported?

## Character
Can it distinguish principal identity from broader kind/community and singular beings from populations?

## Memory
Can it classify permanent, recurring, historical, seasonal, temporary, joke-only and superseded material?

## Atlas
Can physical, civil, division, owner, route, encounter, state, weather and visibility layers remain separable while sharing stable IDs?

## Art
Before rendering can production answer WHERE, WHEN, WHO, WHY, SOURCE, STATE and FORBIDDEN?

If not, block production.
