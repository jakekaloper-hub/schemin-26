# UNIVERSE OS V1.2 — ACCEPTANCE FRAMEWORK V1

A phase passes only after build, test, audit, repair, retest and independent QA.

## Required domains
- authority / provenance;
- ontology;
- geography / Atlas;
- routes / travel;
- civilization;
- memory / state;
- institutions;
- cross-OS contracts;
- mutation governance;
- query consistency;
- visual packets.

## Blocking principles
- one canonical location ID per active place;
- no renderer-owned canon;
- no unresolved singular/population drift;
- no unreachable required venue;
- no silent state reset;
- no hard division borders that contradict shared habitation;
- no downstream fork of world truth.

## Promotion
Universe OS V1.2 and Atlas Control Plane V2 promote together only when all blocking tests are green.
