## Mission
Promote the existing world stack into a governed living-world simulation without creating a second geography system.

## Ownership
### Universe OS owns
- world truth;
- ontology;
- civilization;
- history and memory;
- institutions;
- persistent world state;
- controlled mutations.

### Atlas Control Plane owns
- spatial representation of Universe truth;
- containment and adjacency;
- travel topology;
- hydrology relationships;
- map layers;
- horizon/visibility;
- spatial QA and map products.

### Character Control owns
principal body and visual identity.

### Memo OS
provides verified weekly evidence and proposed deltas.

### Novel OS / Art
consume shared truth and may not create upstream canon.

## Change pipeline
PROPOSE → PROVENANCE → CLASSIFY → IMPACT ANALYSIS → TEST → APPROVE → MUTATE → REBUILD DEPENDENTS → RECEIPT.

Chat statements may initiate a proposal but durable state changes require repository-governed mutation records.
