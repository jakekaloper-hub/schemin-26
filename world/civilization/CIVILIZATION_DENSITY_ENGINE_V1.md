# CIVILIZATION DENSITY ENGINE V1

**Status:** RELEASE CANDIDATE

## Principle
The world must feel inhabited between Sundays, but the engine must not create named canon merely to decorate an image.

## Method
Civilization texture is represented first as unnamed, confidence-tagged settlement contexts attached to physical zones and active locations.

Placement reasons include:
RIVER_CROSSING, PORT, MOUNTAIN_PASS, ROAD_JUNCTION, HIGH_GROUND, FERTILE_BASIN, RESOURCE_SOURCE, ESTATE_ACCESS, WETLAND_CAUSEWAY, LEAGUE_INSTITUTION, DEFENSIBLE_RIDGE, COASTAL_TRADE.

New named settlements still require the governed location-candidate/promotion path.

## Art / Novel use
Consumers may depict ordinary roads, labor, markets, fields, quays, inns, couriers and service structures consistent with a context without treating incidental details as named canon.
