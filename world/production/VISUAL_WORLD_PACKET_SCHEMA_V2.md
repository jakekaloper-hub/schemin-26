# VISUAL WORLD PACKET SCHEMA V2

**Status:** PHASE 11 CANDIDATE

Every exterior visual packet must resolve one stable location ID and carry the same world truth consumed by Memo/Novel.

## WORLD
- physical region
- civil context
- division presence
- owner domain
- ordinary inhabitants
- institutions
- economy
- entering state
- weather

## ATLAS
- arrival routes
- water/elevation relationship
- camera direction
- foreground terrain
- midground route/settlement
- background topography
- visible landmarks
- forbidden landmarks

## CHARACTER
Character Control remains external authority for body/face/wardrobe/reference pixels. This packet may name the controlling character ID and negative locks but cannot invent a new appearance.

## MEMORY
- prior events
- active scars
- recurring objects
- prohibited literalization

## TYPOGRAPHY
Exact approved names only. Generated text is false by default.

Renderer may alter style, lens, lighting and composition. Renderer may not alter topology, region, route, hydrology, domain identity or persistent state.
