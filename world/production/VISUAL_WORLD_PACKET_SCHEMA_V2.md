# VISUAL WORLD PACKET SCHEMA V2

**Status:** RELEASE CANDIDATE

Every exterior illustration request hydrates one packet from shared Universe/Atlas truth before image generation.

## World
location ID, physical region, state, history, institutions, ordinary inhabitants, weather.

## Atlas
civil context, division presence, owner domain, arrival routes, water/elevation context, camera direction, foreground/midground/background geography, visible/forbidden landmarks and historical overlays.

## Domain
architecture, materials, economy, settlement context and division culture.

## Character
current Character Control reference, ontology, body locks and negative locks. Missing exact renderer-addressable character reference may still block principal rendering.

## Memory
active scars, recurring objects, prior events and prohibited literalization.

## Typography
exact approved names/labels; generated text remains prohibited where deterministic overlay is required.

## Renderer boundary
Style, lens, lighting and composition may vary. Topology, region, route, hydrology, domain identity and persistent state may not.
