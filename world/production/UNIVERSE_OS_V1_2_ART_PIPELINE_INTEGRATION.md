# ART PIPELINE — UNIVERSE OS V1.2 INTEGRATION

**Status:** ACTIVE WITH UNIVERSE OS V1.2

Exterior visual production consumes Visual World Packet V2 compiled from shared Universe and Atlas data.

Required before render: active location ID, physical zone, domain/division context, arrival routes, water/elevation context, persistent landmarks/state, ordinary inhabitant context, Character Control packet for principals, and deterministic typography plan.

The renderer may choose style, lighting, lens and composition. It may not move geography, invent active routes, rename canon places, change ontology, reset state or promote generated scenery.

Recognizable principal-character rendering remains subject to the current Character Reference Asset Authority gate.
