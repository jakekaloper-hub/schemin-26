# EXPANSION-AWARE GENERATION WORKFLOW V1

**Status:** PHASE 1 PRODUCTION CONTROL
**Consumers:** Weekly Memo OS, Novel OS, visual-generation pipeline

## Prime rule

A generator never receives "make a cool fantasy football setting."

It receives a hydrated world packet.

## 1. Scene resolution order

LEAGUE FACT
→ EVENT CLASS
→ HOME / NEUTRAL POLICY
→ ACTIVE LOCATION SEARCH
→ CANDIDATE SEARCH IF NEEDED
→ PHYSICAL ZONE
→ DIVISION OVERLAY
→ ROUTE / ARRIVAL
→ CURRENT WORLD STATE
→ CHARACTER CANON
→ STORY PURPOSE
→ VISUAL / PROSE GENERATION

## 2. World Packet

Every scene should resolve:

### Location
- location_id or candidate_id;
- name;
- location class;
- canon/lifecycle status;
- physical zone;
- parent location if sub-location;
- event eligibility.

### Environment
- terrain;
- climate;
- ecology;
- materials;
- architecture;
- ambient industries;
- ordinary inhabitants;
- time/season/weather.

### Continuity
- prior events;
- scars/damage;
- repairs/cleanup;
- reputation;
- recurring props/landmarks.

### Travel
- arrival route;
- plausible mode;
- constraints;
- whether arrival is shown or merely known upstream.

### Division
- applicable cultural overlay;
- food/hospitality motifs;
- prohibited over-theming.

### Character
- canonical owner/character ID;
- mounted visual reference packet;
- ontology;
- current equipment/state;
- explicit prohibited morphology/drift.

### Event
- verified score/result only when known;
- matchup context;
- wager facts;
- home/away;
- event class;
- narrative consequences allowed.

## 3. Candidate packet

If a candidate site is used provisionally, add:
- candidate status;
- activation trigger;
- technology translation;
- unresolved fields;
- "do not canonize generated background detail" warning.

The final published artifact may establish evidence, but post-production decides what survives.

## 4. Character reference law

World grounding does not replace character grounding.

Visual production must mount the approved character reference assets when a principal appears.

Text-only character names are insufficient for visual fidelity.

## 5. Location reference packet

For recurring/promoted locations, create reusable packets containing:
- approved wide establishing view;
- landmark list;
- material palette described in words;
- horizon/terrain profile;
- weather range;
- architectural grammar;
- forbidden substitutions;
- prior-damage notes.

A future generation may change camera, time and staging while preserving location identity.

## 6. Modernity translation packet

When a scene uses a modernity-flavored candidate, include:

MODERN REFERENCE FUNCTION:
What the Commissioner wants the audience to recognize.

SCHEMIN TRANSLATION:
The world-consistent institution.

KEEP:
social rhythm, humor, layout logic, recognizable activity.

REMOVE/TRANSLATE:
electronics, engines, firearms, modern communications, literal corporate ownership unless separately approved.

Example:
"airport comedy" becomes a crowded courier/caravan terminal with gates, baggage, delayed departures, ticket counters and arrival halls—without jetliners.

## 7. Weekly Memo workflow

Before Story Room:
1. hydrate verified league evidence;
2. resolve six matchup venues;
3. reuse owner/home sites by default;
4. identify no more than the justified number of new candidate reveals;
5. hydrate world state;
6. lock page-by-page scene geography before image generation;
7. render;
8. perform location-continuity QA;
9. after release, classify new evidence.

## 8. Novel OS workflow

Novel prose may explore more of an established location than the memo showed.

But it must:
- preserve the memo event;
- preserve active location state;
- use travel constraints;
- distinguish public knowledge from POV knowledge;
- not use a candidate as settled canon without marking its provisional status in production notes.

## 9. Anti-random-backdrop test

Reject a scene if:
- another active location already fits better;
- terrain contradicts zone;
- owner home is ignored without override;
- rare-neutral site is used merely because it looks cinematic;
- Division motif drives geology;
- generated detail creates a new city/road/landmark without approval.

## 10. Three questions every frame must answer

1. **Where are we?**
2. **Who normally lives/works here?**
3. **What happened here before today?**

For a first-use candidate, question 3 may be:
"What was this place for before the Twelve arrived?"

This protects the Stranger Test and prevents the universe from feeling like sets built for fantasy owners.

## 11. Post-release writeback

After publication:
- Scout extracts factual event evidence;
- Librarian classifies site evidence;
- Architect decides whether candidate remains candidate, becomes provisional LOC, or stays temporary;
- state ledger receives accepted consequences;
- Umpire audits;
- Closer approves promotion.

**Production principle:** generation consumes canon; governance creates canon.
