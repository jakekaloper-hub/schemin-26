# WORLD MEMORY ENGINE V1

**Status:** RELEASE CANDIDATE

World memory is a typed overlay on stable entities and locations. Memory may change state, reputation or historical meaning; it does not rewrite base geography.

Classes: PERMANENT, RECURRING, HISTORICAL, SEASONAL, TEMPORARY, JOKE_EVENT_ONLY, RUMOR, SUPERSEDED.

The initial machine backfill is derived from the active World State Event ledger. Temporary physical effects require an explicit recovery/cleanup mutation before reset, while the historical event itself may remain remembered.

Atlas binding: geographically relevant memory references stable location IDs. Memo release creates evidence; Atlas Phase 5 governance controls durable state mutation.
