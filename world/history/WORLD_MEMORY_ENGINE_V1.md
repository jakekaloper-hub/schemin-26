# WORLD MEMORY ENGINE V1

**Status:** PHASE 4 CANDIDATE

The Memory Engine preserves meaningful history without allowing every joke or visual metaphor to harden into geography.

## Classes
PERMANENT, RECURRING, HISTORICAL, SEASONAL, TEMPORARY, JOKE_EVENT_ONLY, RUMOR, SUPERSEDED.

## Rules
- Memory may bind to stable location, route, region or institution IDs.
- Memory overlays Atlas geography; it does not rewrite base terrain.
- Temporary physical effects need explicit expiry/restoration.
- Historical reputation may persist after physical cleanup.
- Published jokes can remain social memory without becoming permanent architecture.
- Superseded visual canon remains historical evidence only.
