# WORLD MEMORY ENGINE V1

World Memory preserves consequences without allowing every weekly joke to become permanent geography.

## Classes
PERMANENT, RECURRING, HISTORICAL, SEASONAL, TEMPORARY, JOKE_EVENT_ONLY, RUMOR, SUPERSEDED.

A memory can carry more than one class where effects differ by layer. Example: Country Club contamination is HISTORICAL as memory but TEMPORARY as physical state.

## Spatial binding
Geographically relevant memory binds to stable IDs:
- location_id
- route_id where needed
- region/institution relationships where needed

Memory overlays Atlas geography; it does not rewrite base terrain.

## Reset law
A temporary physical state expires only when its expiry condition is met or a governed restoration mutation records the change. Historical memory may remain after physical cleanup.

## Anti-literalization
A delivery gag, humiliation prop or image composition never becomes a city, species, road or permanent monument without explicit promotion.
