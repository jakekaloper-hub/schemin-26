# SCHEMIN ’26 — CHARACTER SOURCE-BYTE & NATIVE RENDER LIFECYCLE PROGRAM

**Date:** 2026-10-01  
**Status:** PROGRAM PLAN / PHASE 0 COMPLETE / PHASE 1 NEXT  
**Baseline budget:** ChatGPT Plus only  
**Program owner:** Bullpen — Closer  
**Primary domain owners:** Librarian, Architect, Warden, Groundskeeper, Umpire  
**Supporting:** Scout, Setup Man, Pitching Coach, Analyst  
**Canonical repos:** `schemin-26` + shared Bullpen governance

## Mission

Close the character-reference portability problem end-to-end without making any paid renderer, plugin, API, or credit-metered provider a required dependency.

Target operating chain:

`Commissioner-approved source bytes → durable project-owned storage → fresh hash verification → source authority receipt → native ChatGPT mount intent → per-subject binding → governed generation → output receipt → independent Character QA → consumer integration → derived overview rebuild → production activation → regression/monitoring`

## Governing constraints

1. Budget baseline = **ChatGPT Plus only**.
2. No provider asset name, tag, preview, composite, or generated redraw can establish identity authority.
3. The 12-character overview is always derived convenience, never primary authority.
4. No synthetic replacement is allowed for missing Commissioner source bytes.
5. Character Control Plane v2 remains RELEASE_CANDIDATE / NOT ACTIVE until its own release gates close.
6. Current Character Canon remains authority until explicit promotion.
7. All character-bearing generation fails closed when exact source authority or binding proof is missing.
8. No paid external renderer may become a blocker.
9. Native ChatGPT capability is the funded default execution route when it can satisfy the governed mount/binding contract.
10. If native execution cannot prove the contract, state = HOLD / RENDER_DEFERRED rather than semantic fallback.
