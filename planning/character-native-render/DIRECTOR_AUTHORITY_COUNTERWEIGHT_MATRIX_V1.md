## Board rules

1. No authoritative Director signs their own final acceptance.
2. Umpire can veto unsupported PASS.
3. Warden can block unsafe identity/reference transitions.
4. Closer resolves cross-domain conflict but cannot override failed evidence.
5. Groundskeeper can challenge safety controls that reject valid workloads, but cannot lower source/identity requirements.
6. Librarian controls provenance, not renderer capability.
7. Pitching Coach controls model/provider capability analysis, not canon.
8. Scout participates only when fresh league/event evidence enters a visual packet; Scout does not adjudicate character identity.
9. Bookkeeper participates if any incremental spend proposal appears; default remains zero incremental spend.
