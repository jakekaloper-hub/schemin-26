# Schemin Story Production Graph — 2026 Memo Coverage (Weeks 1–9)

**Mission:** #306  
**Implementation:** PR #307  
**Scope:** all nine 2026 memo cycles currently evidenced by the repository.

## Coverage doctrine
This is a season convergence layer, not a replacement publication authority.

- **Weeks 1–2:** exact publication binaries are external to GitHub. The graph registers the authoritative issue identities and committed recovery/readback receipts, but does not reconstruct missing pages.
- **Weeks 3–9:** repo-native source packets drive matchup Event extraction.
- **Weeks 5, 6 and 9:** repo-native source packets contain enough character/location/action structure to hydrate reusable Scene objects without invention.
- **Weeks 3, 4, 7 and 8:** Event truth is represented, while scene hydration remains bounded by the available source contracts. No inferred camera/location state is promoted merely to improve coverage.

## Season-level outputs
The implementation is designed to produce:

- **9 Memo Issue nodes**
- **42 recoverable matchup Events** from Weeks 3–9
- **12 Character Chronicle timelines**
- **cross-season relationship histories**
- **place-memory projections from source-resolved Scenes**
- **one 2026 compiler manifest** spanning all nine memo issues
- **selective invalidation** by result, character, location, copy, audio and presentation dependencies
- **artifact lineage receipts** that cannot claim render execution before execution occurs

## Source-integrity rule
More coverage is not automatically better. If the repo lacks exact page bytes, LOC resolution, character binding or source authority, the graph must preserve the gap rather than synthesize a false Scene.

## Completion rule
Season implementation is complete when:
1. all nine issue nodes validate;
2. Weeks 3–9 each expose six matchup Events;
3. all 12 current characters receive the expected recoverable cross-season matchup history;
4. source-resolved Scenes compile across more than one Memo generation;
5. W1/W2 external-binary gaps remain explicit;
6. dedicated Story Graph CI passes on exact HEAD;
7. independent Umpire acceptance remains a separate non-self-certifiable gate for promotion/merge.
