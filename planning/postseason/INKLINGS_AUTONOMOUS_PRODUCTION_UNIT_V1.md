# Inklings — Autonomous Postseason Production Unit V1

**Founder authority:** F11 (2026-11-18), in FOUNDER_CHAMPIONSHIP_ISLAND_DECISIONS_2026-11-18.md.  
**Operating boundary:** Project-local production unit inside Schemin’s existing Bullpen + Novel/Memo authority; not a 19th Director, not actual historical authors, and not a replacement for independent Umpire.  
**Execution status:** Deterministic creative packet compilation demonstrably executed on a connected Mac (Node.js), with 56 cards/168 stages, eleven annual narrative movements and eleven negative/positive regression checks. Autonomous *independent AI workers* have NOT been installed or certified.

## Permanent production responsibility

Inklings owns creative production work from a fact-frozen postseason matchup to a publishable draft. Its product is not consultation alone:

1. **Story architect:** defines emotional stakes, historical return, 2-POV access and linkage to the other playoff arenas.
2. **Encounter choreographer:** makes a distinct three-stage head-to-head challenge, with escalation and both challengers' agency; never determines ESPN outcomes.
3. **World dramaturge:** validates bridge, stadium, weather, service routes, architecture, changes and era-specific technology against Atlas proposals.
4. **Character editor:** reconciles correct season-specific identities and locked modern visual references before character-facing renders.
5. **Commentary producer:** authors professional play-by-play, color analysis, field-report cues, live-screen inserts and central-bracket transitions.
6. **Continuity editor:** tracks contender residences, bye privileges, each eliminated team’s beach descent, veterans’ social hierarchy and prior location scars.
7. **Memorial editor:** protects Farrell remembrance and champion succession separately from slapstick beachfront scenes.
8. **Final script editor:** delivers cohesive scene and page packets to Memo/Novel/Visual production rather than a collage of published-author styles.

All eight are **functional workstations**, not claims of distinct live AI agents. The existing eight author-method lenses are selective editorial evaluation methods; staff execution is under the Beat Writer and existing product directors.

## Job lifecycle

Input: frozen league match row + Founder V2 arena + year-specific island site + approved human/character identity + valid media production rules.

`SOURCE_LOCKED → SITE_BOUND → STAGES_WRITTEN → POV_DRAFTED → COMMENTARY_DRAFTED → CONTINUITY_CHECKED → VISUAL_PACKET_READY → INDEPENDENT_QA → PUBLISHED`.

If a source is missing, enter `BLOCKED_SOURCE`. If an arena is unpromoted, enter `HOLD_ATLAS`. If historical owner identity or character asset reference is unknown, produce only disambiguated **team-slot** drafts and hold full character render. If independent QA cannot be evidenced, no publication.

A valid completed Inklings production MUST have source-provenance record, three distinct escalating stage beats, two meaningful contender actions, central bracket consequence, camp/beach evolution, current-as-of technology, camera plans, media script, visual reference bindings, independent Umpire review and actual publish receipt.
