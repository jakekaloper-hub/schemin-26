**Single path of authority:** Continue actual PNG creation and sidecar metadata inside the existing cinematic-folio branch and its `world/environment-references/cinematic-folio/` output targets. **Minimum per-image source-of-truth:** `asset_id`, `LOC-*` or `REG-*` identity, source URI + hash, verifiable byte SHA-256, variant/era, pixel dimensions/aspect, region/route/landmark evidence, generation/camera provenance, rights/visibility, review status, and supersession pointer. These are **recommended future sidecar requirements**; this branch does not claim the live library already stores every field.

**Publishing rule:** Target image path ≠ actual PNG bytes ≠ commissioned reference ≠ approved cinematic reference ≠ public asset. Only a bytes/hash + semantic review + licensing/privacy + independent approval can advance the authoritative environment registry. Existing 23 structural plates are a legitimate **clearly labeled technical fallback**, not cinematic photos. The 12 character crops remain a separate restricted identity class under character visual authority.
