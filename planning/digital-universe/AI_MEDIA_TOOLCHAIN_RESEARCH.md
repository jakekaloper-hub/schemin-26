# AI Media Toolchain — Research Brief

Status: architecture established; vendor selection requires current-market verification before commitment.

## Capability adapters
1. **Image / keyframe** — character-consistent key art, environments, inserts.
2. **Motion / video** — image-to-video, controlled camera motion, short cinematic shots.
3. **Narration / voice** — announcer narration first; optional character voices only under explicit consent/identity rules.
4. **Sound** — ambience, impacts, transitions and licensed/generative music.
5. **Edit / composition** — assemble shots, typography, captions, scores, narration and audio.
6. **Web media delivery** — responsive encoding, poster frames, CDN and adaptive loading.

## Evaluation rubric
Character/reference fidelity; controllability; API availability; reproducibility; commercial-use terms; provenance; latency; cost; output resolution; moderation constraints; data retention/privacy; vendor longevity; automation support.

## Adapter doctrine
No provider-specific IDs in the Weekly Story Package. Provider details live in adapter configuration and media provenance.

## Initial production strategy
Do not attempt fully generated multi-minute films weekly. Use approved artwork as visual anchors, produce short controlled motion shots, then edit those with factual overlays and narration. This maximizes continuity while containing cost and generation variance.

## Research gate
Before naming a production vendor, compare current offerings and terms against the rubric above. Record date of evaluation because this market changes quickly.
