# Risks and Release Gates

| Risk | Gate |
|---|---|
| stale/wrong league facts | Data Gateway validation + freshness visible |
| character drift | canonical reference check before media approval |
| historical rewrite | immutable original editions + versioned WSP |
| generated-media hallucination | every cinematic beat linked to approved story/factual basis |
| voice identity/consent | no character voice deployment without explicit policy/consent |
| music/media rights | rights metadata required before publish |
| vendor lock-in | adapter interfaces + portable asset manifest |
| mobile performance | budgets, poster frames, lazy load, responsive encodes |
| inaccessible motion/audio | captions, semantic text, reduced motion, mute controls |
| runaway weekly workload | tiered production scope |
| cost explosion | generation budgets per week + candidate limits |
| accidental auto-publish | explicit human release gate |

## Required release gates
FACT CHECK → CANON CHECK → EDITORIAL CHECK → MEDIA RIGHTS/CONSENT → ACCESSIBILITY → MOBILE/PERFORMANCE → JAKE RELEASE.
