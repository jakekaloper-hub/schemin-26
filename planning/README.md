# Planning — Bounded Program & Pre-Release Work

**Authority:** The Groundskeeper + owning program authority

Planning is a lifecycle state, not a permanent shadow subsystem.

Every program here must resolve to one of:
- PROMOTED
- CLOSED
- HOLD
- CANCELLED

Active work may remain here while it is genuinely pre-release, remediation or gated program planning. Once operational, durable runtime/control artifacts move to the owning subsystem; planning history may remain as provenance or move to archive according to policy.
