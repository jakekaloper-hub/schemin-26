## Lock criterion

A character is not fully clean until:
1. active title is exact;
2. body/species/props remain consistent;
3. machine-readable identity registries agree;
4. production indexes point to the current lock;
5. conflicting historical material is clearly isolated or deleted;
6. anti-drift tests prevent reintroduction.
