## Retrospective
Root ambiguity: Schemin evolved faster than its organizational namespace. Useful project functions acquired executive-sounding titles; creative meaning, visual direction, canon authority and AI execution were sometimes discussed as one creative/generation domain; documentation could describe controls before runtime enforcement existed.

Controls now preventing recurrence:
- fixed 18-Director constitutional boundary;
- capability-first authority matrix;
- negative authority clauses;
- explicit project-function classification;
- fail-closed context/render packets;
- independent Umpire release veto;
- repository control-registry entry;
- adversarial organizational tests;
- PR #32 runtime boundary remains independently gated.

Portable Bullpen learning:
1. Project roles must never gain universal executive authority by naming convention.
2. Separate semantic/creative authority, canonical authority, technical execution and independent certification.
3. For high-risk generative workflows, evidence of reference selection is not evidence of renderer attachment.
4. Every project adapter should declare A/R/C/QA/V, negative authority and source-of-truth precedence.
5. Documentary governance requires executable tests or explicit NOT-YET-RUNTIME status.

These lessons are portable; Schemin lore, league rules and character specifics are not.
