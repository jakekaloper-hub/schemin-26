## Mixed-domain rule

A data incident may block a downstream deliverable without taking ownership of that deliverable.

Example:

```text
ESPN roster mismatch
→ Data Gateway / Scout owns truth resolution

ESPN roster mismatch affecting Weekly Memo
→ SCK/Closer coordinates
→ Data authority resolves truth
→ Weekly Memo OS retains publication authority
```

This distinction prevents a source-of-truth specialist from accidentally becoming the publication executive.
