## Decision
Do not create Director #19.
Create a Schemin-specific VISUAL_DIRECTION_LEAD project function with bounded decision rights over visual thesis, composition, cinematography, visual grammar and cross-artifact visual continuity. This role is NOT a canonical Bullpen Director. It operates under a canonical executive sponsor and cannot override Librarian canon, Pitching Coach AI-system authority, GM publication UX authority, or Umpire release veto.
