# Schemin '26 Zero-Base Operating Model V1
status: PHASE_4_REVIEWED

## Design principle
Ignore current titles; model the decision domains required to turn Commissioner intent and verified league events into durable Schemin products.

## Required domains
1. Executive intent/arbitration.
2. League truth and historical evidence.
3. Canon/identity/provenance.
4. World/geography/ontology.
5. Narrative/editorial/POV.
6. Visual direction: visual thesis, composition, cinematography, continuity grammar, page-to-page visual coherence.
7. Design/publication UX: typography, hierarchy, mobile readability, final presentation.
8. AI production: models, prompt/render compilation, authenticated reference injection, provider routing.
9. Production engineering/reliability.
10. Production operations/delivery.
11. Independent QA/governance.
12. Learning/regression/archive.

## Value streams
### Weekly Memo
intent -> league truth -> story selection -> narrative treatment -> canon/world resolution -> issue/page architecture -> visual direction -> render contract/reference proof -> generation -> layout -> domain QA -> independent release gate -> publication -> retrospective.

### Living Novel
verified history -> causal state -> world/POV -> narrative architecture -> manuscript -> visual planning -> canon/world resolution -> illustration -> literary/continuity QA -> release candidate -> archive.

### Visual-only/live look
event truth -> story thesis -> canon/world resolution -> visual brief -> reference proof -> generation -> identity/visual QA -> release.

## Separation-of-duty laws
- Canon authority cannot be inferred from creative direction.
- Visual direction cannot mutate character/world canon.
- AI production cannot relax render invariants.
- Production cannot self-certify release.
- Umpire remains independent of artifact creation.
- Jake approves canon-changing and constitutional decisions.

## Phase 4 audit
Bug ORG-0401 P1: "creative" previously mixed narrative, visual direction and design.
Fix: three distinct domains: narrative/editorial, visual direction, publication design.
Bug ORG-0402 P1: AI generation could be mistaken for visual direction.
Fix: AI production is a technical execution domain downstream of approved visual/canon contracts.
Test: each value stream has evidence, creative, visual, AI, QA and release boundaries where applicable.
Polish: shared domains serve Memo and Novel without duplicating truth/canon.
Sign-off: Closer APPROVED zero-base model; Groundskeeper APPROVED flow; Beat Writer APPROVED narrative/visual separation; Pitching Coach APPROVED AI boundary; Umpire APPROVED separation of duties.
