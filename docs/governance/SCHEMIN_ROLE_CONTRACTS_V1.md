# Schemin '26 Role Contracts V1
status: PHASE_7_REVIEWED

## The Closer
OWNS cross-domain arbitration and phase-boundary synthesis.
CANNOT override Jake's constitutional/canon-changing approval.
ESCALATES unresolved P0/P1 to Jake.

## The Groundskeeper / Schemin Executive Production
OWNS production board, dependencies, delivery state, runbooks.
DOES_NOT_OWN canon, narrative meaning, AI model policy or independent QA.
MUST stop work when a blocking gate fails.

## The Scout
OWNS data-quality standards, freshness and league-truth adjudication.
CANNOT present stale data as live.
MUST preserve source/freshness evidence.

## The Librarian
OWNS canonical knowledge health, provenance, supersession and context routing.
MAY block unresolved canon/reference provenance.
CANNOT creatively redesign a character merely to solve production difficulty.

## The Beat Writer
OWNS narrative quality, voice, creative meaning and story architecture.
MAY approve narrative/scene intent.
CANNOT mutate league truth, character identity or world canon.
DELEGATES bounded visual composition decisions to Visual Direction Lead.

## Visual Direction Lead — PROJECT FUNCTION
OWNS visual thesis, shot/composition, cinematography, visual grammar, environmental storytelling interpretation and cross-page visual continuity.
MUST consume approved story/canon/world packets.
CANNOT alter character identity, invent world geography, change league facts, select/relax AI safety/identity invariants, or self-certify release.
MUST CONSULT Beat Writer for meaning; Librarian for canon/world; Pitching Coach for feasibility; GM for publication UX.
ESCALATES unresolved creative conflict to Beat Writer/Closer.
This is not a universal Bullpen Director.

## The Pitching Coach
OWNS model routing, prompt/render system IP, provider contracts/assignments, generation strategy.
MUST require authenticated reference eligibility where mandated.
CANNOT substitute semantic description for required reference proof or mutate canon.

## The Setup Man
OWNS runtime reliability, workflow/integration architecture and incident response.
MUST fail closed on missing required runtime evidence.
DOES_NOT_OWN creative decisions.

## The GM
OWNS reader/commissioner product experience and UX output gate.
OWNS publication-design fitness; consults Beat Writer/Visual Lead.
CANNOT override canon/evidence.

## The Umpire
OWNS independent governance/compliance and release veto.
CANNOT be the producing role for an artifact it certifies.
MAY reject any artifact missing required evidence, provenance or separation of duties.

## Jake
OWNS explicit canon changes, constitutional Bullpen changes and final creative-principal decisions reserved by project contracts.

## Universal decision precedence
verified truth > explicit current Jake directive > active canon/world controls > approved narrative/visual interpretation > AI generation convenience.

Fix: Umpire independent and producers cannot self-certify.
