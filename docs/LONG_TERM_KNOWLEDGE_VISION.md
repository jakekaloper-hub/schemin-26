# Schemin '26 — Long-Term Knowledge Vision

**Prepared under:** FLA Bullpen Librarian / CKO doctrine  
**Horizon:** 2026 season → postseason archive → reusable 2027 operating memory

## North star

Schemin '26 should become a **small, legible institutional memory system** for one fantasy league—not a pile of chat transcripts and not a clone of the larger FLA platform.

A future session should be able to answer four questions within minutes:

1. What is true now?
2. What rules govern this task?
3. Why was the current system designed this way?
4. What changed since the last time this workflow ran?

## Long-term knowledge layers

### 1. Structural truth
Slow-changing facts: league identity, format, divisions, franchise/owner mapping, keeper rules, draft-pick mechanics.

### 2. Canon
Owner characters, approved visual references, rename continuity, league lore that should persist.

### 3. Operating doctrine
Memo OS, Mercer, Data Gateway, SCK, QA and release contracts.

### 4. Seasonal state
Current rosters, standings, schedule, assets, weekly outcomes. This should come from validated data/snapshots, not hand-edited narrative docs.

### 5. Decision memory
ADRs, trade/keeper decisions, OS patches, rejected approaches, reasons for reversals.

### 6. Produced artifacts
Weekly memos, artwork, PDFs, reports and release manifests. These are outputs and benchmarks, not automatically governing doctrine.

### 7. Archive
Superseded versions and completed-season evidence retained for provenance without polluting current routing.

## Anti-bloat principle

Do not create a new permanent folder, agent, ledger or ceremony unless it solves a recurring retrieval, authority, provenance, or execution problem.

## Seasonal lifecycle

```text
PRESEASON
→ establish structural truth + canon + asset ledgers

IN SEASON
→ verified weekly state
→ domain execution
→ decisions + releases
→ targeted documentation updates

POSTSEASON
→ freeze final 2026 state
→ season retrospective
→ archive weekly transient material
→ promote durable lessons into 2027 doctrine
→ retire obsolete RC / temporary controls
```

## 2027 handoff objective

At the end of 2026, a new Schemin '27 repository or season branch should be creatable from:
- structural league config;
- final character canon;
- validated keeper/draft-pick ledger;
- proven Data Gateway contracts;
- certified Memo OS doctrine;
- Mercer decision framework;
- selected regression tests;
- ADR history.

Weekly clutter should not be required to understand the system.
