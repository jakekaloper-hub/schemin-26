# SYSTEM TESTS EMBEDDED IN STORYBOARD

The prototype must prove:
1. exact scores can coexist with literary pages without becoming dashboard UI;
2. character recognition survives painterly compositions;
3. artifacts can carry factual density;
4. prose can vary from near-zero to medium/high without breaking book identity;
5. one chapter can move among radically different inhabitants/environments and still feel unified;
6. Week 1 can initialize durable world state for Week 2.

# FIRST VISUAL PROTOTYPE

Do not render all 16 pages blindly.

Produce Pages **10–11** first as the Character/Continuity stress test:
- two important canonical humans/humanoids;
- Championship Belt contamination risk;
- Trade Jedi no-belt rule;
- retriever;
- signature weapons;
- exact score artifact;
- prose + painting integration.

If Pages 10–11 pass, produce Pages 12–14 as the artifact/material-language test, then expand outward.

# UMPIRE RENDER GATE

Every rendered page must be checked against:
- character identity;
- temporal knowledge;
- artifact custody;
- factual text;
- typography legibility;
- crop/mobile legibility;
- visual continuity;
- accidental future-event leakage.

A beautiful page that violates canon is a failed page.
