# BULLPEN OPERATIONAL LEAD — PROLOGUE PRODUCTION

**Status:** ACTIVE

## Operational lead
**Closer** owns delivery and final gate authority.

## Production command
- **Librarian:** source packets, reference provenance, final asset catalog, GitHub storage.
- **Beat Writer + Editor:** final narration and page-level prose.
- **Architect:** spread architecture, gutter, hierarchy, composition contract.
- **Art Department / Pitching Coach:** render strategy and controlled generation.
- **Clubhouse Manager:** character dignity and recognition.
- **Umpire:** facts, temporal integrity, canon, typography, duplication.
- **Groundskeeper:** queue, handoffs, failure recovery, completion tracking.
- **Closer:** adjudicates disagreement, rejects failures, locks PASS spreads, advances queue.

## Operating rule
Bullpen does not return routine decisions to Jake.

For each pair:
Librarian Source Packet -> Architect -> Umpire Preflight -> Clean Art -> Character QA -> Literary Typesetting -> Critic -> Final Umpire -> Render QA -> Closer -> Lock -> next spread.

A rendered image is not a completed spread.
A storyboard is not a completed spread.
A completed spread contains final narration + final art + final typography + audit PASS.

## User-facing checkpoint
Normal checkpoint is the completed assembled Prologue PDF, not intermediate approvals.

Escalate only for:
1. genuinely insufficient factual evidence;
2. material conflict between authoritative canon sources;
3. permanent redefinition of a major character;
4. fundamentally different creative directions requiring Jake's authorship.
