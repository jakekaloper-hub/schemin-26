# PROLOGUE — PRE-SHOW RENDER AUDIT PROTOCOL

**Status:** BINDING
**Applies:** every Chronicle visual before Jake sees it.

## 1. CHARACTER LOCK
If a page contains a character, Art must attach the exact Character Master packet and any Jake-approved visual reference before generation.

Automatic reject for:
- wrong species/body;
- wrong face/head;
- wrong signature wardrobe;
- missing/incorrect companion;
- wrong weapon/prop;
- wrong Belt custody;
- character duplicated;
- team rename changing character identity;
- invented character standing in for canon.

No multi-character generation until each visible character has independently passed recognition.

## 2. TEXT OWNERSHIP
Generated art does not own factual typography.

The image layer may contain texture, illegible marks, ornamental glyphs and damaged non-semantic writing.

All readable:
- prose;
- headings;
- owner/team names;
- scores;
- dates;
- years;
- standings;
- draft rounds;
- player names;
- keeper costs;
- pick ownership;
- artifact labels

is added exactly once during composition from verified source text.

**No duplicated text:** if prose/headline exists in the composition layer, it must not also be generated inside the illustration. If the model accidentally renders a readable duplicate/near-duplicate, reject or remove it before composition.

## 3. BULLPEN PRE-SHOW LOOP
Every page:
1. Art creates image layer.
2. Critic checks composition/storytelling.
3. Clubhouse Manager checks character dignity/recognition.
4. Umpire checks canon, temporal knowledge and facts.
5. Editor checks prose placement and duplication.
6. Render QA checks crop, gutter, phone readability and artifacts.
7. Fix/re-render as required.
8. Closer approves.
9. Only approved page may be shown to Jake.

## 4. WAVE A SPECIAL RULE
P1–P4 contain no fully introduced character. Do not insert a random archivist, hero silhouette, Trade Jedi, Belt Keeper, or ensemble merely to make the opening more dramatic.

P1–P2: Archive.
P3: evidence/artifacts.
P4: identity/rename law using non-authoritative abstract archival layers unless exact aliases are verified/typeset.

## 5. PAGE OUTPUT
Illustration and typography are separate production layers until final composition.
One authoritative instance of each text string.
No generated factual inscription is accepted because it happens to look correct.

## 6. SHOW GATE
A beautiful failure remains a failure.
Jake sees only Closer-approved work.
