## VISUAL STORYTELLING CORRECTION — BINDING

Jake identified a repeated failure mode in approved-direction experiments: decorative stacks of labeled books such as “TRADES / DRAFTS / RIVALRIES / RECEIPTS / LEGENDS / BROTHERHOOD / THE BELT / AND WHAT COMES NEXT.”

**This device is prohibited.**

### Why it fails
It tells the reader the themes as a list instead of dramatizing them. The object is decorative exposition, not evidence from the world. Repeating it makes the Chronicle feel like designed marketing collateral rather than a lived history.

### New rule — NO THEME LABEL PROP
Do not place abstract Chronicle themes on:
- book spines;
- signs;
- banners;
- plaques;
- scroll headings;
- wall labels;
- crates;
- decorative objects.

Words such as trades, drafts, rivalries, receipts, legends, brotherhood, Belt, history, consequences, etc. must not appear merely to explain what the visual is “about.”

### Visuals must perform narrative work
Every prominent object must satisfy at least one:
1. **Evidence:** a verified artifact or materially plausible carrier of verified evidence.
2. **Character:** reveals an inhabitant through canonical possession/use/environment.
3. **Consequence:** physically shows something that happened or was changed by an event.
4. **Foreshadowing:** a restrained setup supported by temporal knowledge, never future-result leakage.
5. **World:** establishes geography/material culture without unsupported lore.

If an object only names a theme, remove it.

### Show, do not label
Instead of a book labeled **TRADES**, show a verified exchange through altered pick tokens, crossed ownership marks, or two hands completing an exchange.
Instead of **DRAFTS**, show the actual draft board losing names and unequal opportunity in physical form.
Instead of **RIVALRIES**, show preserved opposing artifacts, scars, receipts, or spatial tension supported by history.
Instead of **RECEIPTS**, use actual receipt material only where an event generated one.
Instead of **THE BELT**, show the Championship Belt with its rightful custodian.
Instead of **BROTHERHOOD**, earn relationship through shared scene behavior.
Instead of **LEGENDS**, let the Archive's age and incomplete evidence create legend.
Instead of **AND WHAT COMES NEXT**, use the blank 2026 ledger.

### Umpire visual audit question
For every major foreground/midground object ask:

> If all written labels disappeared, would this object still tell the story?

If no, it fails.

### Repeat-content audit
Before any render advances:
- compare against prior approved pages;
- reject repeated symbolic props unless repetition is narratively intentional;
- recurring motifs must evolve with consequences;
- no visual motif may become filler simply because it looked good previously.
