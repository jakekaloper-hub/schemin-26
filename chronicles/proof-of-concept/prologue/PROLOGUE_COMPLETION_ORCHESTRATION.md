# Mission

# Assembly line

For EVERY spread:

1. **Librarian — Source Packet**
   - manuscript excerpt;
   - evidence ledger references;
   - Character Master packets;
   - approved visual references;
   - prior spread continuity;
   - known failed-generation lessons.

2. **Architect — Spread Manifest**
   - left/right narrative jobs;
   - gutter;
   - prose zones;
   - painting/artifact zones;
   - page-turn hook;
   - mobile crop/legibility.

3. **Umpire — Preflight**
   - FACT/CANON/STORY separation;
   - temporal knowledge;
   - exact strings requiring external typesetting;
   - forbidden future events;
   - character prohibitions.

4. **Art Department — Clean Art**
   - render visual layer;
   - no authoritative prose baked into generated art;
   - no fake readable factual text;
   - characters generated only from locked reference packet.

5. **Character QA**
   - compare every visible character to recognition authority;
   - automatic reject on wrong species/body/face/hair/wardrobe/prop/companion/Belt custody.

6. **Compositor — Literary Text Layer**
   - manuscript text typeset once;
   - no duplicated semantic text;
   - exact names/numbers/dates from evidence only;
   - spread-level hierarchy inherited from P1–P2.

7. **Critic**
   - literary/art integration;
   - emotional progression;
   - composition;
   - no poster/stat-card regression.

8. **Umpire — Final Truth Audit**
   - factual strings;
   - chronology;
   - canon;
   - rename resolution;
   - artifact truth.

9. **Render QA**
   - phone;
   - tablet;
   - desktop;
   - printable spread;
   - gutter;
   - text contrast;
   - crop.

10. **Closer**
    - PASS → lock and advance automatically.
    - FAIL → return only to responsible stage, fix, re-audit.
    - ESCALATE only under Jake's established escalation conditions.

# Character-production law

Do NOT solve ensemble continuity by asking one generation to invent the whole cast.

For character spreads:
- produce/lock individual canonical character art first;
- reuse locked plates/reference IDs;
- compose multi-character spreads from approved components where needed;
- no character enters final Prologue without a recognition PASS.

# Typography-production law

The approved P1–P2 image establishes appearance, but final Chronicle production separates:
- **art layer** = environment, characters, objects, painterly texture;
- **text layer** = all authoritative literary/factual text.

No semantic duplication between them.

If an art generation produces meaningful readable text, remove/replace it before final lock.

# Failure memory

Every rejected spread writes a compact failure record:
- failure class;
- symptom;
- root cause;
- fix;
- prevention rule;
- affected page/reference.

Successful novel solutions are also recorded so later spreads reuse them.

The Prologue is not finished when all images exist.

It is finished when:
- every spread has Closer PASS;
- every character has recognition PASS;
- every factual string has Umpire PASS;

- all spreads behave like the same physical book as P1–P2;
- manuscript continuity survives page turns;
- mobile/print checks pass;
- the final Clean Page lands directly into Chapter I;
- final assembled Prologue receives a whole-book retrospective and canon lock.
