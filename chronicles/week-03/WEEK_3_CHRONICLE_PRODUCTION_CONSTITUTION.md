# SCHEMIN '26 — WEEK 3 CHRONICLE PRODUCTION CONSTITUTION

**Status:** ACTIVE / PRE-PRODUCTION
**Program:** Pro Schemin' Chronicles
**Authority:** Bullpen board + Jake creative direction
**Foundation dependency:** `bullpen/PRO_SCHEMIN_WORLD_FOUNDATION_PHASE0_PASS1.md`
**Purpose:** Produce Week 3 as the first native illustrated chronicle: a book whose real PSFL results become persistent fictional history.

## 1. Product Definition
Week 3 is not an enlarged Week 2 recap. It is an illustrated fantasy chronicle. Written narrative, illustration, typography, paper, artifacts and factual league evidence are composed together.

The page belongs to the story.

## 2. Creative Constitution
### Literary
Original Schemin voice using:
- mythic historical depth, geography, journeys and inherited consequence;
- grounded interpersonal conflict, competing motives, reversals and multiple perspectives;
- exact PSFL receipts and league-specific comedy;
- quiet scenes as well as spectacle;
- original prose: do not imitate a living author's distinctive prose.

### Visual
Original painterly fantasy language using:
- hand-crafted animation principles: expressive acting, atmospheric weather, tactile environments, warmth, motion and quiet wonder;
- monumental epic-fantasy scale, ancient materiality, wilderness, ruins and journeys;
- PSFL-specific Southern/American locations and objects;
- no Japanese cultural coding unless canon independently requires it;
- no copying specific films, compositions, characters or protected designs.

### Book object
Default surface is warm paper/parchment/printed stock, not black UI.
Illustration and prose share the page. Art may invade margins, dissolve into paper, frame copy, become maps/artifacts, or command full spreads.
One coherent Schemin publishing identity governs folios, type hierarchy, grid, ornaments and paper behavior; regional variation is subtle.

## 3. Truth Model
Every consequential assertion is one of:
- FACT — verified league/NFL evidence.
- CANON — established Schemin identity/history/world state.
- INTERPRETATION — editorial reading of facts.
- STORY — invented dramatization/dialogue/scene connective tissue.

STORY may dramatize FACT/CANON but never overwrite them.

## 4. Production Chain
```
SOURCE LOCK
→ WEEK 1–2 CANON HYDRATION
→ WEEK 3 EVENT LEDGER
→ NARRATIVE SIGNIFICANCE PASS
→ SIX CHAPTER DOSSIERS
→ SELECT RICHEST PROTOTYPE CHAPTER
→ PLOT ARCHITECT PASS

→ CRITIC / CONTINUITY PASS
→ LITERARY EDIT PASS
→ STORYBOARD
→ PAGE/SPREAD COMPOSITION
→ READER EXPERIENCE PASS
→ TRUTH + CANON + RENDER QA
→ JAKE REVIEW
→ CHAPTER LOCK
→ CANON DELTA COMMIT
→ NEXT CHAPTER
→ ISSUE ASSEMBLY
→ RELEASE AUDIT
```

Do not write all six chapters simultaneously before validating the first complete chapter.

## 5. Story Budget
No fixed word quota. Assign depth based on narrative significance.
Expected flagship range may be ~2,000–4,000+ words, but story controls length.
Avoid disguised play-by-play. Every retained scene must develop character, world, conflict, consequence, humor, atmosphere or future narrative debt.

Default chapter grammar:
BEFORE → APPROACH → ENCOUNTER → COMPLICATION → TURNING POINT → CONSEQUENCE → ECHO.

## 6. Visual Rhythm
Do not require one hero illustration per page.
Possible rhythm:
painting → prose → vignette → artifact → whitespace → painting → dramatic spread → aftermath.

Full cinematic spreads are reserved for earned moments. Spot art, maps, ledgers, receipts, sketches, letters and environmental artifacts carry secondary storytelling.

## 7. Character Rules
- Twelve-Protagonist Rule: all twelve accumulate meaningful history across the season.
- Character Dignity Rule: comedy/humiliation may create consequences but may not flatten an inhabitant into one joke.
- Team renames never redesign the owner character.
- ObiWan/Trade Jedi has NO championship belt unless canon changes.
- Fictional persona characterization is not a psychological claim about the real manager.

## 8. Persistence
Accepted chapters may create canon deltas:
- character condition/location/reputation/objective;
- relationship tension/debt/promise;
- artifact ownership/location/condition;
- location change/damage;
- knowledge/rumor state;
- narrative debts and payoffs.

Draft material never becomes canon merely because it was generated.

## 9. Three Hard Gates
### Truth Gate
Scores, records, players, transactions, standings, timing and cited historical facts correct.

### Canon Gate
Character identity, artifacts, relationships, prior events, geography status and knowledge boundaries consistent.

### Render Gate
Final page inspected for readable text, correct names/numbers, character fidelity, composition, typography, cropping and mobile readability.

Any blocking failure returns the asset to revision.

## 10. Reader Experience Pass
A reviewer who did not author the chapter answers:
1. Where was I bored?
2. Where was I confused?
3. What did I remember?
4. Which character changed?
5. What question makes me turn the page?
6. Did statistics feel like history rather than a report?
7. Did art and prose feel authored together?

## 11. Week 3 Chapter Dossier Contract
Each matchup receives:
- verified matchup/result/evidence;
- both canonical character packets;
- Week 1 and Week 2 intersections;
- entering record/reputation;
- current setting candidates with canon status;
- factual high-impact events;
- narrative significance candidates;
- each character's scene-level want (STORY until accepted);
- dramatic question;
- POV recommendation;
- Before/Approach/Encounter/Complication/Turning Point/Consequence/Echo outline;
- required artifacts/props;
- illustration opportunities;
- quiet-scene opportunity;
- humor mechanism;
- unresolved prior narrative debts;
- possible new debts (PROPOSED only);
- explicit DO NOT list;
- fact/canon/story provenance table.
