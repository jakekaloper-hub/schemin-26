# CHRONICLE PAIRED-SPREAD LOOP v1.0
## Bullpen + Librarian + Umpire Production Control

**Status:** BINDING
**Atomic production unit:** exactly one facing-page pair
**Visual benchmark:** approved Prologue P1–P2
**Character authority:** Master Character Canon + Jake-approved visual references
**Core prohibition:** no unintended duplicate artwork, characters, props, scenes, or semantic text.

# LOOP

For each pair P(n)–P(n+1):

**0 — LOAD**
Librarian loads only the required packet:
- approved preceding spread;
- manuscript range for current pair;
- evidence/fact lock;
- Character Master entries for characters actually appearing;
- approved visual references;
- failure/solution ledger.

**1 — ARCHITECT**
Define the pair as one composition:
- left-page purpose;
- right-page purpose;
- visual transition across gutter;
- prose zones;
- image zones;
- page-turn hook.
No independent poster pages.

**2 — DUPLICATION PLAN**
Before rendering, create a spread inventory:
- CHARACTER INSTANCES;
- COMPANION INSTANCES;
- SIGNATURE PROPS;
- MAJOR ARTIFACTS;
- ENVIRONMENTAL LANDMARKS;
- AUTHORITATIVE TEXT STRINGS.

Every intended repeated object must be explicitly marked **REPEAT INTENTIONAL**.
Everything else has maximum instance count = 1.

Examples:
- one Trade Jedi means exactly one Trade Jedi;
- one golden retriever means exactly one golden retriever unless story explicitly requires otherwise;
- Belt appears only with Belt Keeper when applicable;
- Dark Horse appears once when called for;
- no mirrored/echoed duplicate character across gutter;
- no duplicate book, sword, dog, receipt or portrait caused by generation unless composition explicitly calls for repetition.

**3 — UMPIRE PREFLIGHT**
Audit:
FACT / CANON / STORY / temporal knowledge / rename state / Belt custody / exact factual strings.
Reject unsupported additions before art begins.

**4 — CLEAN ART RENDER**
Generate only the visual layer.
Rules:
- no authoritative prose;
- no readable fake names/scores/dates;
- no title baked twice;
- no contact sheet;
- no future-page thumbnails;
- no accidental duplicate subjects;
- character reference lock mandatory.

**5 — DUPLICATION VISION AUDIT**
Critic inspects the full spread at native size and thumbnail size.

Checklist:
- duplicate character?
- duplicate companion?
- duplicate limb/head/body caused by generation?
- duplicated signature prop?
- same character unintentionally shown twice?
- mirrored subject across gutter?
- repeated artifact with no story purpose?
- repeated environmental focal object?
- visual clone caused by compositing?
- duplicate semantic text inside art?

Any YES without **REPEAT INTENTIONAL** = automatic REJECT.

**6 — CHARACTER QA**
For each character:
OWNER MATCH / TEAM MAP / BODY-SPECIES / FACE-HEAD / WARDROBE / PROPS / COMPANION / SILHOUETTE / NO CROSS-CONTAMINATION / RENAME SAFE.
Any failure = regenerate before typography.

**7 — COMPOSITION**
Apply authoritative manuscript typography exactly once.
Generated art text is removed/obscured where it could be read as semantic information.

**8 — TEXT DEDUP AUDIT**
Create normalized string inventory.
Reject:
- repeated title;
- repeated paragraph;
- duplicate caption;
- same score/name/date in two places unless narrative explicitly requires it;
- generated pseudo-text competing with real prose;
- body copy accidentally repeated across facing pages.

**9 — BOOK QA**
Compare directly with approved P1–P2:
- same physical Chronicle;
- compatible border/material/lighting seriousness;
- literary depth;
- integrated prose/art;
- gutter safety;
- mobile readability;
- no magazine/poster/card regression.

**10 — CLOSER**
PASS → lock pair → record solution → advance to next pair automatically.
FAIL → identify responsible stage → repair only that stage → rerun downstream audits.
Do not show Jake failed candidates.

# PAIR QUEUE

P1–P2 — LOCKED official benchmark.
P3–P4 — current production pair.
P5–P6 — blocked until P3–P4 PASS.
P7–P8 — blocked until P5–P6 PASS.
Continue sequentially through the Prologue.

# CHARACTER SPREAD SPECIAL RULE

A character-bearing pair cannot enter Step 4 until its approved reference stack is attached.

If two different characters share a spread, each receives an independent identity packet. The model is not permitted to blend their traits.

If a character appears on both pages intentionally as sequential storytelling, mark:
**REPEAT INTENTIONAL — SAME CHARACTER / DIFFERENT STORY BEAT**
and audit that the second appearance is continuity, not an accidental clone.

# FINAL RULE

**Nothing duplicated by accident. Nothing changed by accident. Nothing shown before Bullpen passes it.**

The pair is the unit of thought.
The pair is the unit of art.
The pair is the unit of QA.
The pair is the unit of approval.
