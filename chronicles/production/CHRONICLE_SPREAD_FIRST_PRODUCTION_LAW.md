# CHRONICLE SPREAD-FIRST PRODUCTION LAW
## Binding Bullpen Production Contract

**Status:** BINDING
**Applies to:** Prologue, Chapter I, and subsequent Schemin Chronicle pages unless Jake explicitly changes it.

# 1. SPREAD IS THE ATOMIC UNIT

The production template is always a paired physical-book spread:

- P1–P2
- P3–P4
- P5–P6
- P7–P8
- continuing in pairs.

A single page may have its own narrative job, but it is never designed, rendered, audited, or presented without its facing page.

Every spread must answer:
- what changes from left to right?
- where does the eye enter?
- where does it cross the gutter?
- what earns the page turn?
- how does prose density balance across both pages?
- what information belongs to image versus typeset text?

# 2. P1–P2 IS THE BOOK TEMPLATE, NOT A CLONE

P1–P2 establishes the governing grammar for the entire Chronicle:
- premium illustrated physical-book object;
- cinematic art integrated with literature;
- tactile paper/materiality;
- prose embedded into the composition;
- disciplined negative space;
- no black dashboard/UI panels;
- no poster/card design;
- one coherent spread rather than two unrelated graphics.

Later spreads inherit the grammar, NOT identical layout.

P3–P4, P5–P6, etc. must feel like the same book while changing composition according to story.

# 3. AUTHORITATIVE TEXT EXISTS ONCE

**No duplicated meaningful text inside a visual.**

For every spread, the compositor owns:
- title;
- section heading;
- prose;
- names;
- team names;
- dates;
- years;
- scores;
- draft rounds;
- keeper costs;
- standings;
- quotations;
- artifact labels intended to be read.

Image generation must NOT create another readable version of those strings.

Allowed generated marks:
- illegible handwriting texture;
- non-semantic ink;
- damaged marks;
- ornamental glyphs;
- blurred/unreadable document texture.

Not allowed:
- generated title behind typeset title;
- fake second paragraph beneath real prose;
- repeated team name on prop and text layer unless story intentionally requires it and Umpire approves;
- generated fake scores/names/dates;
- decorative pseudo-text that is legible enough to be mistaken for canon.

**One semantic string → one authoritative rendered instance.**

# 4. CHARACTER REFERENCE LOCK

No character may appear from a generic text prompt alone.

Before rendering a spread containing a character, Art Department must attach the applicable Character Master packet and approved visual reference(s).

Recognition hierarchy:
1. Jake-approved visual reference where available.
2. Character Master canonical description.
3. previously Bullpen-locked Chronicle character plate.
4. team name is NEVER a redesign instruction.

Automatic reject:
- wrong species/body;
- wrong face/head;
- wrong hair;
- wrong signature wardrobe;
- missing/incorrect signature prop;
- wrong companion;
- wrong Belt custody;
- duplicated character;
- omitted character when composition claims their presence;
- rename causing redesign.

Special immutable examples:
- ObiWan / Trade Jedi: youthful blond human, green energy sword, golden retriever, NO BELT.
- Austin Byars / Belt Keeper / His Majesty's Blood: approved ashen long-black-haired rune-armored reference, massive rune sword, Belt; NO beard/crown.
- Donkey Kong: Arsenal Centaur, NEVER gorilla.
- TDS: reptilian humanoid with long dreadlocks before Week 2.
- Mud Dogs: mud-covered dog/wolf beast, not human biker.
- El Niño: elemental storm humanoid, not human wizard.
- Dr. Duckhook: visibly anthropomorphic white duck golfer.
- Chili: Chili Outlaw + Dark Horse; no superseded animal hybrid.

# 5. PRE-SHOW BULLPEN AUDIT

Nothing is shown to Jake merely because it rendered successfully.

Every spread runs:

**Create → Art Critic → Character Recognition Audit → Umpire Truth Audit → Typography Audit → Book/Spread Audit → Fix → Re-render/re-compose as needed → Closer Approval → Show Jake.**

## Art Critic
- composition;
- emotional clarity;
- visual storytelling;
- painterly quality;
- spread continuity.

## Character Audit
- compare each visible inhabitant against reference lock;
- reject identity drift even if image is beautiful.

## Umpire
- temporal knowledge;
- factual claims;
- artifact accuracy;
- no future-event leakage;
- no invented historical detail.

## Typography
- authoritative text appears exactly once;
- no AI gibberish competing with prose;
- punctuation/spelling/name fidelity;
- readable at phone width;
- gutter-safe.

## Book Audit
- same Chronicle object as P1–P2;
- left/right pages function together;
- page turn earned;
- no magazine/poster regression.

## Closer
Only a Closer PASS permits user presentation.

# 6. SPREAD MANIFEST

Every spread receives a manifest before rendering:

- spread ID;
- pages;
- manuscript source range;
- narrative purpose;
- character references;
- FACT strings;
- CANON strings;
- STORY-only elements;
- forbidden future knowledge;
- art-only layer;
- authoritative text layer;
- gutter map;
- mobile-safe text zones;
- acceptance checklist.

# 8. DISPLAY LAW

When a spread is shown to Jake:
- show the audited final spread, not raw generation candidates;
- identify it by page pair;
- summarize any unresolved evidence hold;
- do not call it locked until Jake approves when his approval is requested for a major visual benchmark.

# CLOSER RULING

P1–P2 establishes the book.

Every subsequent pair must answer:
**Does this look, read and behave as though turning the approved P1–P2 page naturally revealed it?**

If not, it fails even when the individual artwork is strong.
