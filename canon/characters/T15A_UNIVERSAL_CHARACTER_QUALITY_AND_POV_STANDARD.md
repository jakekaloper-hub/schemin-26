# CCCP T15A — TWELVE-CHARACTER QUALITY + NARRATIVE POV STANDARD

**Status:** BINDING PRE-ART GATE
**Purpose:** No character enters tomorrow's art run as a mascot/profile only. Every owner must pass the same identity, visual-development, world-continuity and narrative-POV standard.

## Universal four-layer QA

### A. Identity fidelity — release blocking
Owner ID; current team/aliases; canonical identity; species/body architecture; head/face architecture; silhouette/mass; material/palette; signature wardrobe; signature object(s); canonical companion relationship; negative locks; superseded designs; primary-reference provenance.

### B. Illustration quality — equal standard for all 12
Believable anatomy/weight; coherent construction; readable silhouette at thumbnail scale; material specificity; purposeful gesture; motivated light; atmospheric depth; foreground/midground/background storytelling; environmental detail; no generic mascot treatment. Wilson's 2026 Gorilla Warrior is a maturity benchmark, not a composition/species template.

### C. World continuity
Each character has a home-world/environment anchor and may travel through the shared Schemin geography. Scene environment may change; identity cannot. Scale, terrain, weather, architecture and travel relationships must coexist with the shared map. Objects/companions cannot bleed between owners.

### D. Narrative POV
Every character receives a continuing POV packet. POV is not invented psychology presented as fact. It is a controlled storytelling lens derived from verified league events, prior approved memo storytelling, established character/world canon and recurring owner-specific comedy/history.
Each packet must contain:
- worldview/lens;
- visual storytelling grammar;
- reaction-to-winning vocabulary;
- reaction-to-losing vocabulary;
- humor mechanism;
- recurring objects/environments used narratively;
- established wounds/reputations/receipts;
- current-week verified pressure;
- unresolved story threads;
- forbidden characterization shortcuts;
- evidence/provenance;
- confidence: ESTABLISHED / SUPPORTED / PROPOSED.
A weekly memo scene must answer: **Why is this event experienced differently through THIS character than through any of the other eleven?**

## Equal-standard rule
Austin and Pitts require modernization because their supplied identity references are lower rendering quality. That does not create a separate QA bar. All 12 must pass the same A–D standard. High-quality existing art can still fail for weak POV, world inconsistency, stale canon or cross-character contamination.

## Weekly story transaction
VERIFIED WEEK FACT → HISTORICAL/RELATIONSHIP CONTEXT → CHARACTER POV → WORLD CONSEQUENCE → VISUAL BEAT → COPY BEAT → CHARACTER QA → STORY QA.
No future outcome may be implied as fact. No generic heroic pose substitutes for a story beat.

## Acceptance
A character is T15-ready only when:
IDENTITY=PASS; VISUAL_QUALITY=PASS; WORLD_CONTINUITY=PASS; POV_PACKET=PASS; ACTIVE_REFERENCE=PASS; CROSS_CONTAMINATION=PASS.
