# Character Canon Control Plane (CCCP)

**Status:** v1.0 Release Candidate  
**Purpose:** single deterministic entry point for every Schemin '26 character-bearing workflow.

## Non-negotiable runtime
REQUEST → OWNER RESOLUTION → CHARACTER_REGISTRY → ACTIVE PACKAGE → PRIMARY REFERENCE → RENDER CONTRACT → GENERATION → CHARACTER QA → PUBLICATION.

No Memo OS, Novel OS, Chronicles workflow, cover, matchup art, owner spotlight, animation/video or downstream application may independently define a league character.

## Crossroad rule
If active source material conflicts, a reference is missing, or a visual redesign cannot be resolved deterministically, STOP with HUMAN_REVIEW_REQUIRED and ask Jake. Do not infer a compromise.

## Versioning
Old designs are preserved as HISTORICAL/SUPERSEDED. They never seed current generation unless Jake explicitly requests historical reconstruction.

## Acceptance gate
v1.0 becomes ACTIVE only after all 12 packages are migrated, primary-reference assets are registered, alias/red-team tests pass, multi-character contamination tests pass, and Jake approves any unresolved character crossroads.
