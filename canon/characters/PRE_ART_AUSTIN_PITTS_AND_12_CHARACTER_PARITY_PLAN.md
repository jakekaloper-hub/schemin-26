# PRE-ART PRODUCTION PLAN — AUSTIN + PITTS + TWELVE-CHARACTER PARITY

**Execution window:** complete pre-production now; artwork generation deferred to next approved art session.
**Gate:** no generation until Character Director + Narrative Director + Continuity + Visual Director + Umpire sign off the packets.

## Phase 1 — source archaeology
For each of 12 Character IDs, assemble exact evidence ledger from current CCCP package, approved visual reference, Master Canon, Weekly Memo appearances, Chronicles/Novel material where relevant, and verified league-history evidence. Classify every claim ESTABLISHED / SUPPORTED / PROPOSED / RETIRED. Contradictions are surfaced, not averaged.

## Phase 2 — Austin deep specification
Create a production-grade master-reference packet:
- anatomy/silhouette: towering supernatural humanoid champion, not a renamed-team mascot;
- head: hood/shadow dominates; glowing supernatural eyes; unseen face/hair details cannot be overclaimed from low-quality visual;
- materials: layered black armor/cloak, metal/leather/cloth hierarchy;
- identity-critical objects: championship belt + medieval/rune sword;
- world: gothic championship/relic environment integrated into shared map;
- POV: championship memory, burden, survival, relic/legacy language supported by prior memo;
- negatives: king/crown, vampire, blood creature, generic knight, belt omission, rename-driven redesign;
- tomorrow's candidate views: neutral identity hero, 3/4 action, silhouette/profile, material/detail crop, environment-integrated story frame.

## Phase 3 — Pitts deep specification
Create a production-grade master-reference packet:
- anatomy: ONE humanoid reptilian torso/body supporting exactly THREE distinct serpent heads;
- solve neck/shoulder junction explicitly so it reads as one organism, not hydra clutter/three snakes;
- related-but-distinct head expressions without turning heads into separate characters;
- green/gold scales, glowing eyes, dreadlock-like extensions, dark #3 football-warrior identity;
- jungle/waterfall home-world integrated into shared map;
- POV: wounded menace/recovery pressure/multi-headed vigilance only where evidence supports; deeper personality remains controlled/proposed;
- negatives: single head, separate snakes, Medusa, human, extra heads, generic hydra;
- tomorrow's candidate views: neutral identity hero, anatomy study, silhouette, three-head detail, environment-integrated story frame.

## Phase 4 — 12-character parity audit
Score no character numerically. Each receives PASS/HOLD across: identity packet completeness; reference authority; visual construction; material language; silhouette; objects/companions; world anchor; negative locks; POV differentiation; weekly-story grammar; provenance; stale-canon safety.
Austin/Pitts can be HOLD only for the known master-art modernization; any new gap found in another character receives the same treatment.

## Phase 5 — weekly POV packets
Create one persistent owner POV packet per Character ID. It is updated weekly by verified event consequence, not rewritten weekly. Separate:
1. immutable identity;
2. persistent narrative lens;
3. accumulated history/reputation;
4. current-week state/pressure;
5. scene-specific expression.
This prevents visual consistency with narrative amnesia.

## Phase 6 — tomorrow's art-generation contracts
For Austin and Pitts, compile candidate-specific contracts from CCCP only after Phase 1–5 pass. Every generation gets active identity reference + invariants + negative locks + world anchor + narrative intent. Generate candidates, never automatic canon.

Cartography/Continuity: world coexistence.

Only approved candidates become PRIMARY_HIGH; old low-quality references remain historical/supplemental evidence.
