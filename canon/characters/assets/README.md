# Character Canon Vault

Runtime authority is Character ID -> one approved primary asset -> exact bytes -> SHA-256 -> canon version -> verified mount -> eligibility.

Only CANONICAL_ACTIVE records may define identity. CANONICAL_DERIVATIVE may support continuity. HISTORICAL_PUBLISHED and SUPERSEDED_QUARANTINED are excluded from normal production retrieval. DELETE_CANDIDATE requires Librarian review.

The vault is fail-closed while primary bytes are unavailable. Migration contracts do not substitute for image assets.
