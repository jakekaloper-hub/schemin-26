# League & Character Canon

This directory owns durable continuity rules.

High-priority examples:
- ObiWan Jacoby / Jake Kaloper: The Trade Jedi; no championship belt in 2026.
- His Majesty's Blood / Austin Byars: The Belt Keeper identity persists across renames.
- Donkey Kong: Arsenal Centaur character persists across rename.
- Slob on my Dobb: Fart Star character.
- Chili Cheesers / Brandon Pryor: The Chili Outlaw; horse is The Dark Horse.

A team rename never automatically changes the established owner character identity.
