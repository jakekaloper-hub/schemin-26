# Schemin Capability Budget — Phase 0

**Status:** ACTIVE  
**Baseline:** ChatGPT Plus only  
**Budget posture:** zero incremental spend unless Jake explicitly approves otherwise

## Phase 0 decision

Schemin is provider-neutral and must remain operable without purchasing credits from third-party plugins or APIs.

### Default production path

- ChatGPT-native generation/editing capabilities available in the current Plus experience;
- ChatGPT-native file/document/artifact tooling;
- existing GitHub connection at its current access level;
- existing connected services only where no paid upgrade or metered spend is required.

### Unfunded external adapters

Creative Claw, Higgsfield, OpenArt, Runway, Adobe paid workflows, fal.ai, Replicate, ElevenLabs, Cartesia and similar services are optional research/adapters only.

They may not:
- block publication;
- block Character Canon;
- define renderer readiness;
- become the sole holder of required source bytes;
- become the only way to reproduce a release;
- be assumed available next week because trial/free credits exist today.

## Character-system consequence

The Character Control Plane must prove authority, byte identity, source lineage and QA independently of any one renderer.

A provider-specific asset ID can be recorded as evidence but can never substitute for the approved Commissioner source hash.

## Visual-production consequence

If a visual can be produced with ChatGPT-native image generation/editing, that is the default funded route.

If a requested capability cannot be completed within the baseline, the workflow must:
1. degrade gracefully;
2. hold the affected optional feature; or
3. ask Jake for explicit spend authorization.

It must not silently incur or assume paid credits.
