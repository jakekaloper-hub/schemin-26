# SCHEMIN OS CONTRACT MAP V1

## Universe OS provides
- authoritative world entity IDs;
- ontology;
- location identity;
- civilization and institution records;
- historical/world memory;
- persistent world state;
- mutation receipts.

## Atlas Control Plane provides
Derived spatial context over Universe truth:
- physical region;
- containment;
- adjacency;
- route/path;
- hydrology relationship;
- visibility/horizon;
- map-layer membership;
- spatial QA.

Atlas does not create independent canon.

## Character Control provides
- principal body;
- face;
- wardrobe;
- props;
- companions;
- visual negative locks;
- approved reference authority.

Universe/Atlas may classify personhood/population relationships but cannot redesign the principal.

## Memo OS provides
- verified weekly matchup/event evidence;
- home/away;
- outcome;
- current-week production evidence;
- proposed world-state deltas.

Memo OS consumes:
- venue resolution;
- Atlas context;
- entering world state;
- memory/history.

## Novel OS consumes
- world truth;
- ontology;
- routes/travel;
- settlements;
- institutions;
- world memory;
- current state;
- visibility and geography.

Novel invention that would change world truth must become a World State Change Request.

## Art Pipeline consumes
- location/environment packet;
- Atlas spatial context;
- world-state/memory packet;
- character-reference packet;
- deterministic typography plan.

Art Pipeline may NOT:
- create canon proper nouns;
- move locations;
- invent species/populations;
- rewrite route/hydrology;
- erase inherited world state;
- override Character Control;
- automatically mutate world state.

## Shared-ID law
Memo OS, Novel OS, Atlas and Art reference the same Universe IDs. Consumer aliases are display-only and may not fork identity.
