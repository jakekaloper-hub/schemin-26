# SCHEMIN OS CONTRACT MAP V1

**Status:** PHASE 8 CANDIDATE

## Universe OS provides
- world truth;
- ontology;
- populations/communities;
- institutions/economies;
- historical memory;
- persistent state;
- controlled mutations.

## Atlas Control Plane provides
- spatial containment;
- region and domain placement;
- adjacency;
- routes/travel topology;
- hydrology relationships;
- visibility/horizon context;
- spatial QA and map views.

## Character Control provides
- principal body/face;
- wardrobe;
- props;
- companions;
- visual negative locks;
- current reference authority.

## Memo OS provides
- verified weekly event facts;
- matchup/home-away;
- outcome;
- publication evidence;
- proposed world-state deltas.

## Novel OS consumes
- Universe truth;
- Atlas location/travel;
- memory;
- ontology;
- settlement/civil context;
- persistent state.

## Art Pipeline consumes
- environment/world packet;
- Atlas context;
- character-reference packet;
- exact typography plan.

## Prohibitions
No consumer may:
- fork location IDs;
- create new canon names;
- move locations;
- invent species/populations;
- rewrite division membership;
- override Character Control;
- mutate world state without the mutation protocol.
