# SCHEMIN OS CONTRACT MAP V1

## Universe OS provides
- canonical world IDs;
- ontology;
- location identity;
- civilization context;
- institutions;
- memory;
- persistent world state;
- governed mutations.

## Atlas Control Plane provides
Spatial context derived from Universe truth:
- physical region;
- containment / adjacency;
- routes / travel;
- water relationships;
- visibility / horizon;
- map-layer participation;
- spatial QA.

## Character Control provides
- principal body;
- face;
- wardrobe;
- props;
- companions;
- visual negative locks.

## Memo OS provides
- verified weekly events;
- matchup / home-away truth;
- released production evidence;
- proposed world-state deltas.

Memo cannot mutate active world state directly; Atlas Phase 5 / mutation governance handles accepted deltas.

## Novel OS consumes
- Universe truth;
- Atlas location / travel / visibility;
- memory and state;
- ontology;
- settlements and institutions;
- POV knowledge constraints.

## Art Pipeline consumes
- Visual World Packet;
- Atlas context;
- environment reference tier;
- character reference packet;
- deterministic typography plan.

Art may not create names, move locations, invent species, alter ontology, reset state, or promote generated scenery.

## ID law
No consumer may fork or locally rename active LOC-*, ROUTE-*, REG-*, DIV-* or CHAR-* identities.

## Contract test
The same scene request must resolve compatible IDs and current state for Memo, Novel, Atlas and Art.
