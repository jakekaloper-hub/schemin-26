# ORACLE EVENT LEDGER

The Pro Schemin' league is a pressure generator, not a plot generator.

For every candidate Source Canon event record:
- date/week
- verified source event
- affected source identities
- potential Story Canon pressure
- timing: immediate / delayed / symbolic / indirect / none
- existing arc reinforced or complicated
- continuity risk
- possible foreshadowing value
- decision: use / hold / reject
- council rationale

Never silently convert a matchup, trade, waiver move, injury, championship, collapse, joke, or owner behavior into literal fantasy-world action.
