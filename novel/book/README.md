## Replacement rule
Every approved release replaces the same filenames in place. Do not create a competing "master manuscript," "reader edition," or dated current-book file. Historical snapshots belong only in `history/`.

## Editorial gate
No release because a fantasy week ended. A week creates a production deadline, not automatic prose graduation. Writer → Editor → Reader Simulator → continuity/provenance → Visual Director → Umpire must pass before replacement.

## Scale doctrine
Word count is diagnostic, never quota. The v0.2 opening expanded because Draft 0 compressed relationships, ordinary life, class/economic exposure, hospitality, weather, local culture and consequence. Future expansion must earn its length through dramatic material.
