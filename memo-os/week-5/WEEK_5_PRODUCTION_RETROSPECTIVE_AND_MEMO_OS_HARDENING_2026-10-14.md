4. **Production unit** contains specific source identity, printed page number, camera, venue, primary subjects, forbidden mutations, editable numeric text layer, previous/next page references and phone copy budget.
5. **Generate scenic artwork** without scores/standings/names entrusted to diffusion; layout software adds authoritative scores, captions and results table deterministically.
6. **Review generated raster** for each referenced character against specific owner reference; test visual scene accuracy and actual readable page at 390px. Reject wrong matchup, body, costume, limb count, numbers or geography.
7. **Release only** when exactly one locked master exists per required page slot, every asset has hash, visible page number matches slot, combined PDF count matches, mobile previews pass, and independent Umpire receipt exists.
