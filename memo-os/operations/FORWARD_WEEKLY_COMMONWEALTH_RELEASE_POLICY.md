**Effective:** Next unclosed weekly Memo production after this policy is merged.

## Required workflow
1. Obtain commissioner/Flaim-verified week-specific score and matchup lock; preserve provider freshness caveats.
2. Resolve canonical owner, team alias, division, host/visitor venue, legal travel and shared civilization context.
3. Call `memo-os/tests/validate_issue.py::validate_future_week_world_gate` during production QA; passing the gate alone is NOT publication authorization.
4. Build narrative and visual page packets through the existing Memo OS; preserve established character IDs and source-byte render mounts.
5. Perform actual final page/PDF assembly, mobile legibility, scoreboard reconciliation, complete artwork and page-count review.
6. Run **simulated Umpire** as a development review if desired; label it SIMULATED. Do not imply independent certification.
7. Publish only on explicit existing release authority and artifact QA evidence; persist receipts and then update World Evolution through established controls.

## Blocking conditions
Missing fact lock, invalid season/week, unresolved geography, character-reference binding not verified, absent final artifact proof, contradictory event state or false source provenance => HOLD. Historical production artifacts must not be touched by prospective testing.

## Week 6+ handoff
