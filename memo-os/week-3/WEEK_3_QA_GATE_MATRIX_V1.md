# Week 3 QA Gate Matrix V1
**No status may be marked PASS before the corresponding test is actually executed.**

|Gate|Minimum evidence|Failure disposition|
|---|---|---|
|FACT_QA|all deterministic facts trace to FACT_LOCK; derived arithmetic recomputed|PATCH data layer; REGENERATE if composition encodes multiple false facts|
|CHARACTER_QA|owner match, reference likeness, species, body architecture, head/face, wardrobe, signatures, companion/prop, continuity state, contamination/rename safety|single failure = PAGE_REJECT; structural identity error = REGENERATE|
|CONTINUITY_QA|entering state matches ledger; persistent objects/geography/damage maintained|PATCH isolated object/state; REGENERATE structural scene reset|
|MOBILE_QA|native ratio, safe zones, readable copy, no crop/stretch/clipping|PATCH typography/layout if isolated; REGENERATE structurally wrong ratio/composition|
|ORIGINALITY_QA|page serves its own narrative function; art/copy nonredundant; no accidental template repetition|PATCH copy/composition or REGENERATE if concept is derivative/repetitive|

## PATCH
Use only when the underlying composition/story is strong and the defect is isolated and surgically correctable without weakening reference fidelity.

## REGENERATE
Required for wrong character/species/body architecture, wrong matchup mapping, retired identity contamination, multiple factual errors embedded into design, structurally wrong continuity, wrong aspect ratio or fundamentally wrong composition.

## PAGE_LOCK
Only after all applicable gates have actual PASS evidence. Page existence is not Page Lock.

## Final issue
QA ledger/colophon is generated last, after assembled PDF render audit. Any upstream page change invalidates affected certification.
