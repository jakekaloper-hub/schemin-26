# WEEK 4 LIVE RASTER AUDIT — PRODUCTION SALVAGE

**Date:** 2026-10-06
**Status:** PRODUCTION PAUSE / CURRENT RASTERS ARE A SALVAGE CORPUS, NOT A FINAL RELEASE SET
**Trigger:** Commissioner intervention required on nearly every generated page.

## Executive finding

The Week 4 planning stack is materially stronger than the live raster production behavior.

The current failure is not lack of story architecture. It is that the renderer is still being allowed to make too many publication decisions at once:
- composition;
- typography;
- exact team names;
- exact copy;
- character anatomy;
- chapter continuity;
- result modules;
- page-specific visual differentiation.

That makes the Commissioner the first reliable QA layer.

This is unacceptable.

## Week 3 evidence

Week 3 post-production already identified the same systemic risks:
- production efficiency only 3.2/5;
- release QA only 2.8/5;
- raster canon failures escaped written doctrine;
- critical numeric text remained generative;
- repeated headline/parchment/tableau grammar caused visual sameness;
- issue-level composition-family budgeting was missing.

Week 4 live production repeated those problems despite improved planning.

### Common failures

#### 1. The renderer is still acting as layout designer
Header position, title scale, copy block placement and result modules vary page to page.

#### 2. Exact text is not mechanically protected
Examples observed during the live lane:
- D0nkey K0ng spelling drift;
- The Chili Cheesers naming drift;
- wrong GAME OF THE WEEK chrome on non-GOTW pages;
- incorrect/generated scores and records on rejected Page 3 candidates.

#### 3. Current Page 2 is not the locked final manuscript
The saved raster still reflects the longer emergency opener rather than the later locked written-manuscript rewrite.

#### 4. Current Page 3 is not release-clean
It uses a different aspect ratio from most live pages and contains visible corrective patches. It is useful as information-layout evidence, not as a publication master.

#### 5. The hunting chapter has a structural TDS risk
The page art repeatedly resolves TDS as three visually separate snake figures rather than one unmistakable integrated body with exactly three serpent heads. This must be treated as CHARACTER QA risk, even when the page is otherwise attractive.

#### 6. Page 8 and Page 9 initially repeated the same composition
This is exactly the Week 3 visual-fatigue defect: two strong individual images can still fail as a sequence if the camera, staging and visual grammar do not change.

#### 7. Result-page treatment is not yet a true reusable component
Page 7 / Page 10 suggest a useful result-strip language, but the current method still asks the image model to render the critical fields.

#### 8. Aspect-ratio drift exists
Current shared files include both 1024×1536 and 941×1672 page masters.

A final issue cannot mix those casually.

## Classification of current pages

The current images are reclassified as:

**SALVAGE_CORPUS / VISUAL_REFERENCE / NOT AUTOMATICALLY RELEASE_LOCKED**

No image is discarded merely because it needs deterministic remastering.

The preferred strategy is:
- preserve strong artwork;
- repair typography/data deterministically;
- redo only pages with structural visual or character defects;
- normalize all final masters to one canonical page ratio before PDF assembly.

## Commissioner burden failure

The following should never require Commissioner correction during normal production:
- whether a page is GOTW;
- exact team spelling;
- division assignment;
- whether a chapter page repeats the previous composition;
- whether a result module exists;
- whether a character has the correct body plan;
- whether a manuscript version is current;
- whether a page belongs to the same visual family.

Every such correction is a production-system defect, not a Commissioner creative note.

## Bullpen conclusion

Do not continue Page 11 using the current one-page-at-a-time workflow.

Switch immediately to chapter-level production with reusable issue chrome, fixed result modules, deterministic copy, and approved visual-family staging.
