# WEEK 4 — ISSUE-LEVEL DERIVATIVE VISUAL ASSEMBLY RULE
**Applies to:** W4-P03, W4-P23, W4-P24
**State:** REQUIRED FOR WEEK 4 SALVAGE + WEEK 5 PRODUCTION LESSON

## Principle

Front-of-book and issue-level synthesis pages may appear early or late in the final PDF, but when they depict established characters or Atlas locations they must be assembled from the accepted matchup visual corpus.

**Publication order is not production order.**

## W4-P03 — THE BOARD

Character portraits:
- derive from accepted matchup payoff/result pages;
- preserve exact pixels/crops when practical;
- no independent twelve-character generation pass.

## W4-P23 — STATE OF THE REALM

Purpose:
league-level divisional consequence.

Preferred visual:
three divisional windows/panels using accepted matchup environments.

### Burgers visual source family
Use accepted artwork from:
- W4-P04–P07 highlands;
- W4-P08–P10 wetlands.

### Wings visual source family
Use accepted artwork from:
- W4-P11–P13 coastal-resort/golf chapter;
- W4-P14–P16 man-cave chapter.

### Pizza visual source family
Use accepted artwork from:
- W4-P17–P19 Pittsy/financial chapter;
- W4-P20–P22 El Niño/Whipple chapter.

If characters appear:
- source/crop them from accepted matchup pages;
- prefer final payoff/result pages when the purpose is post-Week-4 state;
- never regenerate an ensemble solely for P23.

Do not create a new generic fantasy map that replaces or contradicts the actual matchup geography.

## W4-P24 — POWER RANKINGS

Purpose:
deterministic 1–12 editorial ranking.

Preferred design:
data-first ranking ladder.

If portraits are used:
- reuse the same accepted portrait crops created for W4-P03 where possible;
- otherwise derive from accepted payoff/result pages;
- do not independently regenerate twelve characters.

If background/Atlas art is used:
- derive from accepted matchup environments;
- keep it subordinate to ranking readability;
- do not introduce new geography.

## QA

Reject if:
- a character on P23/P24 visibly differs from that character's matchup wave;
- an Atlas location contradicts the location shown in the accepted matchup art;
- a new costume/state appears only on an issue-level summary page;
- generated ensemble art introduces duplicate/wrong anatomy;
- visual synthesis reduces mobile readability.

## Week 5 rule

Produce in this order:
1. matchup waves;
2. accepted payoff/result pages;
3. reusable portrait/environment crop library;
4. scoreboard;
5. State of the Realm / division synthesis;
6. Power Rankings / other league-wide visual modules;
7. final assembly.

The reader may encounter these pages earlier in the PDF. Production should still happen after their visual source truth exists.
