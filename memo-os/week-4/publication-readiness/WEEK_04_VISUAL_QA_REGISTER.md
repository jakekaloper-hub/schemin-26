# Week 4 Visual QA Register

**Status:** BLOCKED_BY_FINAL_PAGE_PACKETS / PREPARED  
**Authority:** Visual Direction + CAIO + Librarian

For every rendered page record:
- page ID;
- reference assets actually supplied to renderer;
- subject-to-reference binding;
- character identity result;
- anatomy result;
- contamination result;
- world/geography result;
- composition result;
- text-safe-zone result;
- PASS / FAIL;
- defect and rerender receipt.

## Automatic FAIL

- DK not rendered as centaur-bodied Arsenal Gorilla Warrior;
- TDS not exactly one body / three serpent heads;
- ObiWan shown with belt;
- HMB identity substituted;
- obsolete character asset used;
- cross-character contamination;
- generic semantic reconstruction where canonical reference should govern.

Prompt correctness is not proof. Final raster is the QA object.
