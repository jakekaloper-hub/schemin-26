### Art-dominant

- Beer Champion's Belt payoff;

- memorable world establishing shot.

### Deterministic-data dominant
- scoreboard;
- standings;
- Power Rankings;
- Pittsy board;
- waiver/transactions.

Each page packet should include:

**IMAGE TELLS**
- action / environment / body language / object state.

**PROSE TELLS**
- history / irony / causality / memory / consequence / what changed.

Rule:
**never use prose to narrate what the illustration already makes obvious.**

### Tolkien lens

### Martin lens

### Rowling lens
Recurring institutions and objects should return with changed meaning.

### Grisham lens

Show geography through the life occurring there rather than explanatory lore boxes.

### Abercrombie lens

## 19. Premortem / countermeasures

### Failure: too many pages
**Counter:** gate modules default to integrated half-page / page-band treatment.

### Failure: Atlas overwhelms fantasy
**Counter:** world detail must explain consequence, movement or culture.

### Failure: purple prose
**Counter:** one governing image per prose section; facts first; cut ornamental synonyms.

### Failure: repetitive maps
**Counter:** only one full State of the Realm map; transitions use cropped geography / roads / objects.

### Failure: too many objects
**Counter:** one primary carrier object per matchup maximum.

### Failure: fake injury storytelling
**Counter:** distinguish provider roster status, IR, lineup usage and editorial metaphor.

### Failure: invented Pittsy data
**Counter:** exact odds/ledger values remain source-gated.

### Failure: continuity drift
**Counter:** character packet + location packet + prior-state packet before image production.
