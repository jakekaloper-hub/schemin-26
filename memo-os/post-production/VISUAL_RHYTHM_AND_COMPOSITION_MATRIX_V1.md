# VISUAL RHYTHM & COMPOSITION MATRIX V1 — CANDIDATE

For the complete issue track per page:
- camera: extreme-wide / wide / medium / close
- dominant geometry: vertical / diagonal / centered / split / map / table
- character count and scale
- environment prominence
- text density
- headline footprint
- parchment usage
- deterministic-data footprint
- palette/light/time
- emotional intensity

## Controls
1. No successful page template becomes the default issue template.
2. Consecutive pages should not repeat the same dominant camera + text architecture unless intentional continuity requires it.
3. Multi-page chapters require progression: setup → escalation/turn → consequence, not duplicate posters.
4. League-state modules provide visual decompression after cinematic chapters.
5. Mobile legibility outranks ornamental density.
