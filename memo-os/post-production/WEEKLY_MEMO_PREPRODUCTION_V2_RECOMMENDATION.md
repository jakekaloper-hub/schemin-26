# WEEKLY MEMO PREPRODUCTION V2 — BULLPEN RECOMMENDATION

Status: RECOMMENDATION / PATCHES NOT YET PROMOTED

## What Week 3 taught us
The Memo is strongest when private league texture becomes narrative evidence: wagers, deliveries, dialogue, rivalries and recurring environments give prose and illustration something generic fantasy art cannot. Week 3 also demonstrated that page-by-page excellence can accumulate into issue-level drift when the whole issue is not previsualized first.

## Keep
- serialized matchup storytelling when earned;
- variable art/text ratios;
- environmental storytelling;
- personalized league details with provenance;
- league-as-world framing;
- deterministic league-state modules;
- humor embedded inside world-building.

## Stop
- allowing team name/prose to stand in for resolved character references;
- treating prompt compliance as character QA;
- designing every page in isolation;
- letting image-model backgrounds silently define/redefine geography;
- repeating large-headline + parchment + hero composition without issue-level rhythm review;
- silently regenerating approved page masters.

## Character-lock solution
Use immutable identity + continuity overlay + page state. Attach resolved references before generation and certify the final raster. Latest commissioner-approved character correction wins. NOTE: current repository canon now marks Wilson Look/D0nkey K0ng as an ACTIVE gorilla-warrior redesign effective 2026-09-29 and retires the Arsenal Centaur. Any future system must load current repo canon rather than relying on Week 3 memory.

## World-continuity solution
Build a persistent atlas and world-state ledger. Published environments become candidates; intentional persistent elements are extracted and approved. Future scenes coexist spatially and remember consequences.

## Page-previs solution
Complete Issue Previs Board + Page Design Packets before finished generation. Review composition, density, character packets, geography and chapter dependencies globally.

## Personalization system
Register commissioner/verified details before Story Room, classify provenance, and deliberately ask image and prose to carry different information.

## Proposed production order
Evidence/fact scope → current canon load → atlas/world-state load → story intelligence → Story Room → issue architecture → complete previs → environment/reference plates → chapter anchor frames → dependent art → deterministic data typography → transitions → cover/closing → raster QA → PDF/render audit.

## Controls rejected as overengineering
- exact physical mileage between every fantasy location;
- canonizing every background object produced by an image model;
- mandatory dialogue quotas;
- fixed page counts per matchup;
- chronological generation when dependencies suggest otherwise.

## Retrospective simulation
Would PREVENT: missing-reference character mutations, silent continuity resets, many repeated compositions.
Would DETECT EARLIER: world/location contradictions, excessive parchment/headline repetition, mobile density.
Would NOT guarantee prevention: image-model text artifacts or subtle anatomy errors; final-raster QA remains necessary.
Administrative risk: packet burden. Mitigation: one compact structured packet per page and automatic inheritance from chapter/world packets.

## Expected Week 4 advantage
Higher first-pass character fidelity, more coherent geography, stronger issue rhythm, fewer full-page regenerations, clearer provenance and faster lock decisions without reducing narrative ambition.

## Recommendation
Advance these artifacts to controlled acceptance testing against Week 3 before permanent Memo OS promotion. Preserve current V5.4/V5.3 authority until tests pass.
