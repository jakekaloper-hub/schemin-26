# WEEKLY MEMO PREPRODUCTION SYSTEM V2 — CANDIDATE

Status: PATCH CANDIDATE / NOT YET BINDING
Origin: Week 3 post-production learning cycle, 2026-09-29

## Board finding
Week 3 proved the strongest creative formula is verified league reality + commissioner/personalized league intelligence + written narrative + visual storytelling + persistent character/world continuity. Its main systemic weakness was local page excellence without enough global previsualization: sequential generation allowed character, geography, composition and continuity to drift.

## Pre-generation gates
No finished page generation begins until:
1. FACT SCOPE is classified.
2. OWNER→CHARACTER resolution is complete.
3. immutable character packet + current continuity overlay are attached.
4. WORLD LOCATION is resolved in the World Atlas.
5. PAGE DESIGN PACKET is complete.
6. complete-issue PREVIS/RHYTHM board has been reviewed.
7. chapter dependencies and continuity-in/out are known.

## Page Design Packet
Every page records: Page ID; narrative job; story beat; fact dependencies; characters; reference packet IDs; continuity states; world region/location; entering environment state; continuity-out; time/weather/light; camera distance/angle; foreground-midground-background plan; character scale; illustration:text ratio; copy budget; deterministic data overlays; previous/next page relationship; forbidden mutations; mobile risks.

## Character Zero-Drift
Separate IMMUTABLE IDENTITY, CONTINUITY STATE and PAGE STATE. Page state may change pose/action/expression/light; it may not mutate identity or silently reset continuity. Final raster—not prompt intent—must pass Character QA. Latest explicit commissioner-approved correction outranks older reference material.

## World Continuity
Schemin is one persistent world. New scenes may vary radically in genre and environment but must occupy coherent regions with persistent terrain, landmarks, travel relationships and environmental consequences. New locations enter the atlas only after approval. Revisits inherit WORLD_STATE.

## Personalized Story Intelligence
Before Story Room, register supported wagers, chat jokes, deliveries, rivalries, callbacks, commissioner dialogue, trades, traditions and meaningful locations. Label VERIFIED FACT / COMMISSIONER-SUPPLIED FACT / EDITORIAL / STORY / FICTIONALIZATION. Personalization is creative fuel, never license to invent factual claims.

## Art + prose complementarity
For every page answer: what does the image communicate that prose does not, and what does prose communicate that image cannot? Redundant layers require redesign.

## Dependency-aware generation
Preferred order: world/environment reference plates → chapter packets/anchor frames → dependent story pages → deterministic data layers → transitions → cover/closing. Chronological page order is not automatically production order.

## Page Lock
FACT_QA + CHARACTER_QA + CONTINUITY_QA + WORLD_GEOGRAPHY_QA + COMPOSITION_QA + MOBILE_QA + ORIGINALITY_QA must PASS with evidence. Artistic approval alone does not silently waive a failed gate.

## Anti-bureaucracy rule
A control survives only if retrospective simulation shows it prevents/detects meaningful defects or reduces rework. Otherwise retire it.
